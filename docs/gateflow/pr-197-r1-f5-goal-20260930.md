# PR197-R1/F5：HK 年度锚点与不确定财期事实一致目标

## Goal confirmation 与授权

复用用户要求优先修复完整PR197所有成立finding以及原F5裁决。仅主工作树 codex/upload-material-oracle，全部进PR197，不动main。动机成立：同一公司同一报告的财期不应因查询窗口是否包含年度公告而漂移；报告存在但依据不足，不能等价投影为“没有报告”。

目标：discovery与rebuild使用同源、同可信规则的年度截止日证据；窄查询在已有同公司可信本地COMPLETE年度来源时，可正确解析长度型季度标题；证据不存在/冲突时保留不确定性并在公开结果中区分于真实无候选。成功信号是窄/宽窗口及rebuild的一致结果、受损/删除/跨公司/远年/变更年结日证据不被滥用，不恢复“三个月直接猜Q1”。

## 直接证据与 owner

select_hkexnews_report_candidates仅从本次unique公告标题提annual_end_dates；HkexnewsDiscoveryClient按query日期和类别取远端公告后直接选择，不读取本地来源。rebuild_hk_periods持ticker writer batch，从本地同provider/download/nondeleted且staged COMPLETE年度来源取anchors。fiscal_quarter_at要求邻近366天、同年结月份、月末、季度边界，证据不足返回None；selection遇None跳过，后续workflow可报告missing。

财政日历/解析的owner是hk_fiscal_calendar与report selection；证据读取/一致快照由storage拥有；discovery/workflow与rebuild消费同一输入契约和投影。不能从旧fiscal_period、披露日期、文件名、日志或processed季度标签补猜。

## 范围与待收敛的公开契约

Sol计划须核实远端年度来源及同公司本地COMPLETE来源的可信、时序/冲突规则，并复用F4已审公共能力（如果真实存在依赖）；F4尚在plan，不据未来接口实施F5。证据来源ID是审计引用，不得作为财期事实。对“真实报告、无法解析财期”必须给可实施的public owner方案：说明拒绝或失败如何表达、是否需要请求级中止、如何避免unknown period伪造document ID/计数、已处理摘要如何保留，以及与真正空查询/非财报标题区别。若存在不能由已接受goal决定的用户可见取舍，先给具体方案和证据交总控澄清，不下游fallback自行决定。

非目标：不改变Docling抽取、生产转换质量责任、其他市场财期、历史已发布迁移，不引入超范围网络历史爬取、从任何已有季度标签反推、不猜变更年结日/52或53周财政年，不混入F6/F7实现。

## Gate 与验证

当前待依赖/公开contract方案计划；实施前Sol plan、MiMo/Kimi同版Planreview、总控裁决、accepted plan commit。Owner级用真实受控仓储配合远端原始公告：窄窗口仅季度+本地COMPLETE年末、宽窗口相同输入；缺证据/冲突/删除或损坏anchor、跨公司、邻近界限、非月末、显式季度不被改猜；真实adapter/runtime与rebuild投影一致，public不将不确定报告当missing；pytest/全量pyright/覆盖率及README职责门禁。任何新修复项登记本WU裁决和主队列。
