### §5.6 Identity-First Two-Phase Repair — 无新 finding

revision 正确实现了 race-safe repair：
- Phase A: short publication guard → classify → return identity/revision
- Phase B: begin_batch → copy latest published tree → staged identity-first recheck
- Identity-first: any identity/revision change → rollback → discard stale prefetch → back to Phase A
- Same identity → interpret latest integrity + overwrite policy
- Max 3 rounds → typed integrity-repair conflict failure
- Same-target last-writer: later writer sees new revision → re-fetch → publish
- Different-target union: each modifies own target → final published = union

**验证**: `COMPLETE + overwrite_existing=False` 在 Phase A 直接 skip 且不做 target 网络 I/O — 正确。`COMPLETE + overwrite_existing=True` 必须进入正常 overwrite — 正确（CTRL-R01 已修复）。identity/revision 变化时不论 status 都回 Phase A — 正确。

### Overwrite True/False — 无新 finding

- `overwrite=False` + `COMPLETE`: Phase A skip，不做 HTTP — 正确
- `overwrite=False` + `REPAIR_REQUIRED`: 进入 repair（与 overwrite 无关）— 正确
- `overwrite=True` + `COMPLETE`: 进入 overwrite — 正确
- `overwrite=True` + `REPAIR_REQUIRED`: 进入 repair — 正确
- Phase B same identity + `COMPLETE` + `overwrite=True`: apply overwrite — 正确
- Phase B identity change + `COMPLETE`: rollback → Phase A → `overwrite=False` skip / `overwrite=True` re-fetch — 正确

### Same-Target Last-Writer / Different-Target Union — 无新 finding

- Same-target: two writers serialized by writer lock；later writer sees new revision → re-fetch → publish → last-writer wins — 正确
- Different-target: each writer on latest tree copy modifies own target → final = union — 正确
- Invariant: "第二个staging基于第一个已发布视图，无lost update" — 正确
