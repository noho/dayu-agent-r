## 变更动机与 semantic owner 确认

DL-F15 是确定性生命周期 bug。`convert_pdf_bytes_with_docling` 在 attempt 回退循环外构造一次 `DocumentStream`；`run_docling_pdf_conversion` 对同一 callback 调用至多三次。首档 converter 关闭底层 `BytesIO` 后，后续 attempt 读取同一流抛 `ValueError: I/O operation on closed file.`。

真实 production evidence：
- 0066 Q2：attempt 1 `docling-parse/auto` SSL/model 失败 → attempt 2 `pypdfium2/auto` closed-file
- 0700 Q3：同一 closed-file 链

唯一 semantic owner 是 `convert_pdf_bytes_with_docling` 的 `immutable raw bytes → per-attempt DocumentStream` 装配边界。修复放在该 owner 内，未在 runner、caller 或异常处理层添加补偿。
