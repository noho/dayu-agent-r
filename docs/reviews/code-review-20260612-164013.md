### 4. Memory Consumer / Durable Projection 边界一致性

**结论: PASS**

三层消费路径的边界在代码和测试中一致：

1. **Memory direct consumer** (`build_conversation_memory_snapshot_from_events`):
   - 调用 `assistant_final_answer_text_from_run_payload` with `LENIENT_NON_EMPTY`，只读 inline `final_answer`。
   - 不跟随 `terminal_summary_ref` / `terminal_summary_digest`。
   - 测试 `test_memory_direct_consumer_does_not_follow_terminal_descriptor` 验证。

2. **Durable projection / run-input adapter** (`_payload_with_assistant_final_answer` in `run_input.py`):
   - 只对 `RUN_SUCCEEDED` 事件执行 hydrate。
   - inline `final_answer` 已存在时跳过。
   - 否则调用 `assistant_final_answer_continuity_text`（strict resolver）读取 descriptor-backed artifact `content`，merge 为 transient `final_answer`。
   - 测试 `test_durable_projection_hydrates_terminal_content_as_selected_recent_window` 验证。

3. **Compaction material** (strict continuity resolver):
   - 直接使用 `assistant_final_answer_continuity_text` with `STRICT_NON_EMPTY`。
   - 允许 descriptor fallback，malformed descriptor 抛 `HostDurableError`。
   - 测试 `test_continuity_resolver_*` 系列验证。

**关键一致性**: memory consumer 看到的 payload 已经被 durable projection adapter hydrate 过，所以它只需要读 inline `final_answer`。这个两层设计在 `run_input.py:_payload_with_assistant_final_answer` 和 `memory.py:_selected_assistant_item` 之间是正确的。
