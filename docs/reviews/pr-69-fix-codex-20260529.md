### PR-F1-已修复-Tool Trace cold JSONL 复制完整 raw payload

Root cause：`dayu/host/tool_trace.py` 的 `_build_cold_line()` 在已抽取 typed fields、source payload ref/digest、extracted payload ref/digest、operation context refs/digest 与 trace summary 之外，额外写入 `_FIELD_PAYLOAD: event.payload`。这会把 EventLog typed payload 原样复制进 cold JSONL，违反 Phase 13 的 typed whitelist / ref-first 边界。

改动：

- 删除 cold JSONL line 的顶层 `payload` 字段写入。
- 删除仅服务于 raw payload 写入的 `_FIELD_PAYLOAD` 常量。
- 保留 typed fields、`payload_ref` / `payload_digest`、`source_payload_ref` / `source_payload_digest`、`operation_context_refs` / `operation_context_digest`、`trace_summary`、`cold_trace_ref` / `cold_trace_digest`。
- 更新 `tests/host/test_tool_trace_projection.py`：构造同时包含 extracted payload ref、source payload descriptor、operation context 与未白名单 `raw_result` 的事件，断言 cold JSONL 不含顶层 raw `payload` 字段、不泄露 `raw_result`，且仍包含必要 refs/digests。
