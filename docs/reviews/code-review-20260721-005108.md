#### 2. Hub / subscription runtime（`dayu/host/transient_delta.py`）

- `HostTransientDeltaHub`：每次 `open_host` 新建，`runtime_id` 为 `uuid.uuid4()`。`publish` 先分配 `runtime_sequence`（从 1 开始单调递增），构造一次 immutable `HostTransientDelta`，再对 Session 当前订阅快照顺序 `put_nowait`。无 watcher 时仍推进全局序列。hub 已关闭时 `publish` 直接返回。
- `HostTransientDeltaSubscription`：容量 256 的 `asyncio.Queue`。`_offer` 在 queue 满时设 `_overflowed = True` 并 `hub._detach(self)`，后续 offer 直接 return。`drain_nowait` 按 `runtime_sequence` 排空并跳过已 terminal 的 Run。`overflow_error()` 返回新 `HostApiError(UNAVAILABLE, retryable=True, detail=HostUnavailableDetail(component="session_live_stream", reason_code="slow_consumer"))`。
- `wait_ready` 使用 level-triggered 双检查：先 `_is_ready()`，再 `clear()`，再 `_is_ready()` 防止 publish 落在 clear 与 wait 之间丢失唤醒。`_refresh_readiness` 在 `drain_nowait` 后重新检查并按需 set/clear。
- `close` / `_close_from_hub`：幂等，设 `_closed = True`，清空 queue，`_ready.set()` 唤醒等待者。
- `_transient_dedupe_key` 使用 `runtime_id + execution_id + worker_event_index` 的 SHA-256，带版本前缀，opaque equality key。

#### 3. Ingest → publish 时序（`dayu/host/engine_ingest.py`）

- `EngineEventIngestor.__init__` 显式接收 `HostTransientDeltaPublisher`，无 optional/default/fallback。
- `_is_transient_delta_event` 闭集改为三类 delta（`CONTENT_DELTA`、`REASONING_DELTA`、`TOOL_CALL_DELTA`）。
- `_validated_transient_delta_candidate` 按 `EngineEventType` 与精确 `data` 类型映射 Host payload，`else` 分支 `raise ValueError`。
- `EngineIngestResult` 新增 `transient_delta: ValidatedTransientDeltaCandidate | None` 字段，所有现有 result 构造点均已补上 `transient_delta=None`。
- `_IngestValidatedOperation` 从 `_ingest_before_reactive_compaction` 中提取为 module-level frozen dataclass，在 `run_write` 事务内执行 shape + durable context + duplicate/late checks + `_ingest_validated`。
- `_ingest_validated`：三类 delta 共享 `_accepted_no_event_result(_validated_transient_delta_candidate(context, event))`，events 为空元组。`REASONING_DELTA -> PREVIEW` 分支已删除。
- `_finish_ingest`：transaction 成功返回后，发现 `transient_delta is not None` 才调用 `_publish_transient_delta`。该 helper `try/except` 捕获 publisher 意外，只写 sanitized diagnostic（不含 delta 文本或异常正文），然后返回原 ingest result。
- stale/late/wrong identity、rollback、duplicate terminal：均不产生 `transient_delta`，publisher 为 0 calls。测试 `test_transient_transaction_rollback_does_not_publish` 通过 monkeypatch `_IngestValidatedOperation.__call__` 在 validated ingest 后强制抛错证明 transaction 回滚不发布。

#### 4. Scheduler / open_host publisher wiring（`dayu/host/dispatch.py`、`dayu/host/open_host.py`）

- `HostDispatchScheduler.__init__` 和 `HostDispatchScheduler.open` 显式接收 `transient_delta_publisher: HostTransientDeltaPublisher`。
- `_consume_worker_events` 创建 `EngineEventIngestor` 时传入 `self._transient_delta_publisher`。
- `_OpenHostContextManager` 是唯一 production composition root：先创建 `HostTransientDeltaHub()`，再把 hub（作为 publisher）传给 scheduler，把 hub 传给 `_PublicHostHandle`。open 失败时 `transient_delta_hub.close()`。

#### 5. Watcher attach / merge / cleanup（`dayu/host/open_host.py`）

- `_PublicHostHandle.watch_session_events`：同步 public lifecycle gate（`_raise_if_closed`），然后 `hub.subscribe(session_id)` 注册 subscription，再 `submit` cursor future。任一步同步失败回滚 subscription。返回 `_ClosableHostSessionEventIterator`。
- `_ClosableHostSessionEventIterator`：拥有 `cursor_future`、`subscription` 与 lazy `_iterator`（首次 `__anext__` 时创建）。`__anext__` 中 `except BaseException: await self.aclose(); raise` 确保所有终止路径共享幂等 cleanup。`aclose` 幂等：`_closed = True`，关闭 generator，关闭 subscription。
- `_watch_session_events_after` merge loop：
  1. 每轮开头 drain transient → 检查 overflow/closed。
  2. 读 durable batch 后再 drain transient → 检查 overflow/closed。
  3. 遍历 batch events：非 PROGRESS 且有 run_id 的事件（即 terminal）前 drain transient → 检查 overflow/closed → `mark_run_terminal` → yield event。
  4. 空 batch 时 `subscription.wait_ready(_SESSION_WATCH_POLL_INTERVAL_SECONDS)` 替代 `asyncio.sleep`。
- Host close：`hub.close()` 唤醒/清空全部 watcher；iterator 正常结束。不调用 Run cancel API，不生成 terminal。
- `_watch_session_events` 的 `finally: subscription.close()` 确保 generator 异常时也 detach。

## Residual Risk

- transient delivery 在 overflow、detach、断线、Host close、进程崩溃或重启后不可 replay；这是 live-only contract。
- 容量 256 尚无真实负载调优数据，且本 slice 不暴露 public knob。
- durable 与 transient 只有各自内序，没有统一 cursor/总序；同 Run 只承诺 accepted transient 在 terminal 前交付并在 terminal 后 fence。
- hub 只覆盖同一进程、同一 `open_host` runtime；不支持跨 Host instance watcher。
- Slice 2 的 3×1000 stress、deterministic wakeup barrier、真实 Host→Service→CLI slow-consumer E2E 与 README 同步是明确后续 scope。当前实现静态上未违反底层正确性。
