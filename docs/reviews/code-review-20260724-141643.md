### 2-未修复-低-`_public_payload_measure` 非 COLD_LINE 证据的来源路径与 kind 语义不一致

- **严重程度（低）**: 展示层语义不一致，不影响 correctness

## Open Questions

1. **`_repeated_request_findings` 的重复检测是否应跨 Run？** 当前 `_repeated_request_findings`（第 475-531 行）仅在单个 Run 内检测相同 `(run_id, tool_name, normalized_arguments_digest)` 的重复。跨 Run 的相同请求模式（例如模型在多个 Run 中对同一 query 发出相同的工具调用）可能是更有价值的诊断信号，但当前设计未覆盖。这是设计选择而非缺陷——确认是否为有意为之。

2. **`_timing_results` 的 median 计算是否会受极端值影响？** 第 679-681 行使用 `statistics.median()` 计算基准，median 本身对极端值鲁棒。但若 sample 中有一半是极端慢的请求（如全部 timeout），median 会被抬高，导致真正异常的请求反而不触发告警。这是 median-based outlier detection 的固有局限，非实现缺陷。
