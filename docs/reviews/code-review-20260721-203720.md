### 3. Transient delivery owner：per-Session reservation、mailbox + 唯一 in-flight、single-pop、overflow prefix、typed error、readiness、exact-once detach/release、不同 Session/多 watcher 隔离

`dayu/host/transient_delta.py` 完整替换旧 `asyncio.Queue(maxsize=256)` + `drain_nowait()` batch drain 模式：

### 4. Async attach activation：reserve → cursor transaction → no-await recheck/attach/return

### 10. Adversarial failure/cancellation/concurrency pass

- **Factory cancellation**：`await durable_actor.call(cursor)` 被取消时，`except BaseException: reservation.release()` 精确释放，不创建 subscription/iterator。
- **Host close during cursor**：cursor transaction 完成后 `_raise_if_closed()` 捕获 closed 状态，reservation 释放。
- **Partial allocation failure**：iterator 构造失败时 `subscription.close()` 释放 reservation；subscription 构造失败时外层 `reservation.release()` 释放。
- **Overflow race**：`_offer` 在 publisher loop 内同步执行，prospective check 在 mailbox append 前。overflow 后 `_detach_from_fanout` 立即移除，不影响其它 watcher。
- **Idempotent release**：`HostTransientDeltaReservation.release()` 检查 `_released` flag；`subscription.close()` 检查 `_closed` flag。hub close 时先 `_subscriptions.clear()` + `_close_from_hub()`，再 release pending reservations。subscription close 与 hub close 并发时，两次 release 幂等。
- **Iterator close race**：`_HostSessionEventIterator.aclose()` 检查 `_closed` flag。generator finally 调用 `subscription.close()`（幂等）。`__anext__` 异常路径调用 `aclose()` 并 re-raise。
