### 2. docstring 是否准确表达 assistant final-answer continuity text source selection？

**PASS**

- `_terminal_answer.py` module docstring accurately describes:
  - Parsing order: inline `final_answer` first, then terminal summary descriptor with artifact `content` fallback.
  - Artifact `content` is only a success-terminal continuity fallback, not a general terminal summary, diagnostic, episode summary, or evidence-backed fact source.
  - Consumer boundaries: compaction material uses strict resolver with artifact fallback; memory selected recent window consumes inline `final_answer` leniently; durable projection / run-input adapters may hydrate descriptor-backed content into transient `final_answer`.
  - Overlong text truncation is not performed by this module.

- `terminal_summary_payload.py` module docstring accurately describes:
  - This module only reads non-empty text from fields already allowed as assistant final-answer continuity sources.
  - Terminal summary artifact `content` is a fallback text source only in the `RUN_SUCCEEDED` continuity path after descriptor validation.
  - Not a general terminal summary, episode summary, or evidence-backed fact source.

### 3. 是否正确说明 terminal summary artifact content 仅为 RUN_SUCCEEDED continuity fallback？

**PASS**

- `_terminal_answer.py` module docstring: "artifact content 只是成功终态 continuity 的 fallback，不是通用 terminal summary、失败诊断、取消原因、lost 诊断、episode summary 或 evidence-backed fact 来源。"
- `assistant_final_answer_continuity_text` docstring: "terminal summary artifact content 只在 RUN_SUCCEEDED continuity 路径中作为 fallback；失败、取消和 lost 终态的 diagnostic 文本不能通过本 resolver 变成 assistant final answer。"
- `terminal_summary_content_text_from_payload` docstring: "该 content 只供 RUN_SUCCEEDED 的 assistant final-answer continuity fallback 使用，前提是调用方已经通过 terminal summary descriptor 完成 artifact 定位与 digest 校验。它不是失败、取消或 lost 终态的 assistant final answer，也不会被本 helper 升级为 evidence-backed fact。"

All three locations correctly and consistently describe the fallback-only, RUN_SUCCEEDED-only, non-fact semantics.
