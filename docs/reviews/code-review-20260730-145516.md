### 1. init --config 两种位置 exit2/help absence

**实现位置**: `dayu/cli/arg_parsing.py`

**设计**:
- `_build_common_arguments_parent()` 创建不含 `--config` 的公共父解析器
- `_build_runtime_arguments_parent(common_parent)` 在公共父解析器上增加 `--config`
- init 命令使用 `common_parent`，因此 `init --help` 不展示 `--config`
- `parse_cli_args()` 中检查 `init` + `config_dir` 并调用 `parser.error()` 拒绝

**代码证据**:
- `arg_parsing.py:208`: `_register_init_command(subparsers, common_parent)`
- `arg_parsing.py:234-235`:
  ```python
  if parsed_args.command_name == COMMAND_INIT and parsed_args.config_dir is not None:
      parser.error("init 命令不接受 --config")
  ```

**测试覆盖**:
- `test_init_rejects_config_before_and_after_command`: 验证 `--config PATH init` 和 `init --config PATH` 均 exit 2
- `test_init_help_describes_reset_precedence_and_overwrite_boundary`: 验证 `--config` 不在 init help 中

**结论**: 实现正确，测试覆盖完整。

### 5. argparse parent ordering

**实现位置**: `dayu/cli/arg_parsing.py:193-219`

**设计**:
```
common_parent (不含 --config)
    ↓
runtime_parent (含 --config)
    ↓
顶层 parser (使用 runtime_parent)
    ↓
init 子 parser (使用 common_parent)
其他子 parser (使用 runtime_parent)
```

**代码证据**:
- `arg_parsing.py:193-194`: `common_parent` → `runtime_parent`
- `arg_parsing.py:198`: 顶层 parser 使用 `runtime_parent`
- `arg_parsing.py:208`: init 使用 `common_parent`
- `arg_parsing.py:209-219`: 其他命令使用 `runtime_parent`

**结论**: 父解析器顺序正确，参数继承符合预期。
