### Blocker 3：catch precedence 保持

**PASS。** `resolve_fresh_filing_request()` 的 except chain 精确为：

1. `FinsUploadPrevalidationError`（RuntimeError 子类）→ `exc.failure`
2. `FinsUploadUsageError`（ValueError 子类）→ `raise`（re-throw）
3. `(OSError, RuntimeFileLockError)` → `fins_upload_prevalidation_io_failure()`
4. `ValueError` → `fins_upload_prevalidation_corruption_failure()`
5. 其它 `RuntimeError` 与 identity invariant → 不捕获，原样传播（fail-loud）

MRO 验证：`FinsUploadPrevalidationError` 是 `RuntimeError`，不会被 `ValueError`/`OSError` 分支捕获；`FinsUploadUsageError` 是 `ValueError`，在 `except ValueError` 之前被精确 `raise`；`RuntimeFileLockError` 是 `Exception`，只被第 3 分支捕获。
