## Findings

### S1-CR-001 验证结论 — 已修复，未发现遗留问题

S1-CR-001 的修复已由直接证据确认关闭。以下逐项验证：

**Help absence**：
- `session resume --help` 输出不含 `--config`。直接证据：`_register_session_command()` 将 `action_common_parent`（不含 `--config`）传给 `_register_session_resume_action()`（`arg_parsing.py:676`），而 `action_runtime_parent`（含 `--config`）只传给 list 和 purge（`arg_parsing.py:675,677`）。
- `session list --help` 和 `session purge --help` 仍含 `--config`。直接证据：两者使用 `action_runtime_parent`。
- `prompt --help` 和 `interactive --help` 不含 `--config`。直接证据：两者使用 `command_common_parent`（`arg_parsing.py:249-250`）。

**Root-before-command rejection**：
- `dayu-cli --config X session resume --mode interactive` → `_reject_disallowed_explicit_config()`（`arg_parsing.py:310-314`）检测 `command_name == COMMAND_SESSION and session_action == SESSION_ACTION_RESUME`，以 usage error 2 拒绝。
- 测试覆盖：`test_agent_surfaces_reject_config_in_every_parser_position` 的参数化用例 `("--config", "removed-config", "session", "resume", ...)`。

**Command-level rejection**：
- `dayu-cli session --config X resume --mode interactive` → `session` 命令的 `command_runtime_parent` 接受 `--config`，但 `_reject_disallowed_explicit_config()` 在 parse 后、runtime 前拒绝。
- 测试覆盖：`test_agent_surfaces_reject_config_in_every_parser_position` 的参数化用例 `("session", "--config", "removed-config", "resume", ...)`。

**Action-level rejection**：
- `dayu-cli session resume --config X --mode interactive` → resume action 使用 `action_common_parent`（不含 `--config`），argparse 直接拒绝为 usage error 2。
- 测试覆盖：`test_agent_surfaces_reject_config_in_every_parser_position` 的参数化用例 `("session", "resume", ..., "--config", "removed-config")`。

**list/purge 正向不回归**：
- `session list` 和 `session purge` 继续使用 `action_runtime_parent`，root/command/action 三位置 `--config` 均正常映射到 `ParsedCliArgs.config_dir`。
- 测试覆盖：`test_non_agent_runtime_commands_accept_config_before_and_after_command` 覆盖 download、session list（root/command/action）、session purge（root/command/action）共 8 个正向用例。

## 被删除测试的风险评估

以下两个测试被删除：
- `test_interactive_explicit_config_outside_workspace_exits_with_usage_error`
- `test_prompt_explicit_config_outside_workspace_exits_with_usage_error`
