- **输入场景**: snapshot JSON 内容合法、内部 digest 自洽，但 durable row 的 `snapshot_digest` 列值与 JSON 内嵌 `snapshot_digest` 字段不一致（例如通过 SQL 仅修改了 `snapshot_digest` 列但未改 JSON）。

- **预期行为**: 该分支应被测试覆盖，以证明 classifier 能区分"内容 digest 不匹配"与"row 列 digest 不匹配 JSON 内嵌 digest"。

- **直接证据**: Coverage missing 列表包含 1302；测试代码无单独修改 `snapshot_digest` 列的场景。
- **影响**: 覆盖率缺口。该场景对应手动 SQL 修改 digest 列但不改 JSON 的 corruption 模式，实际可能发生。
- **建议改法和验证点**: 新增测试：写入合法 snapshot 后，通过 SQL UPDATE 仅修改 `snapshot_digest` 列（不改 JSON），验证 classifier 返回 `DIGEST_MISMATCH` 且 message 匹配 "row digest does not match"。`pytest tests/host/test_memory_projection.py -q`。
