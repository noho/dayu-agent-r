## Findings

### 1-未修复-[中]-HTML head 的合法子元素 `noscript` 被当作 head 终止符，父链错误且完整旗标/诊断均失真

- **入口/函数**：`DefaultFinsRuntime.create(...).get_read_runtime().read_original_structure` / `query_original_facts` → `OriginalStructure._scan` → `_close_optional`。
- **文件(行号)**：`dayu/fins/processors/original_content.py:44`（`_HEAD_CONTENT` 集合）、`:472-474`（`current == "head" and incoming not in _HEAD_CONTENT` 即按规则闭合 head）、`:681`/`:772`（`parse_status` 由 `self.reasons` 决定）。
- **输入场景**：合法 HTML5 在 head 中包含 `noscript`（`noscript` 是 metadata content，HTML5 “in head” 解析模式会把其放入 head）。最小反例：
  ```html
  <html><head><title>T</title><noscript><link rel='x' href='y'></noscript><body><p>A</p></body></html>
  ```
  以及带显式 `</head>` 的同一文档。
- **实际分支**：遇到 `<noscript>` 起点时调用 `_close_optional(stack, "noscript")`；`noscript` 不在 `_HEAD_CONTENT`（该集合为 `base basefont bgsound link meta noframes script style template title`），于是 `current == "head"` 分支成立，head 在 `noscript` 之前被 `closure="rule"` 闭合，`noscript` 随后被压入 html 的子级。
- **预期行为**：`noscript` 属于 head 内容，head 应保持开启直至 `<body>`；`noscript` 的 parent 应为 head，body 的 parent 为 html，`parse_status` 不应因该合法结构变为 partial。
- **实际行为**（真实 public runtime + 真实 Fs 复现）：
  ```text
  parse_status: complete diagnostics: []
  html      opening=  0 parent=None parent_status=root closure=explicit
  head      opening=  6 parent=0    parent_status=resolved closure=rule
  noscript  opening= 28 parent=0    parent_status=resolved closure=explicit
  body      opening= 72 parent=0    parent_status=resolved closure=explicit
  ```
  `noscript` 的 parent 是 html（start 0），与 head（start 6）成为兄弟，而非 head 子级；`parse_status=complete` 且无 diagnostics。若文档显式写 `</head>`，同一问题表现为 head 已被提前闭合、`</head>` 成为 `unmatched_closing_tag`，`parse_status=partial`——合法文档被误报为不完整。
- **直接证据**：上述 public runtime 输出；同一输入在修复前 `cd37d575` 的 `original_content.py` 上 `noscript` parent 正确为 head（start 6）、显式 head 场景 `complete` 无诊断（独立加载旧文件实测），说明该缺陷由本轮 head 边界规则引入/遗留。`_HEAD_CONTENT` 与 HTML5 head 元数据内容集合相比恰缺 `noscript`。
- **影响**：R1 的物理父链/局部关系契约在合法输入上静默错误；`noscript` 子树（及其中任何结构节点）的 parent/ancestors 错误，且无 partial/unknown 提示。不是内容丢失或版本混用，当前 7 份 anchor 与 API-8 输入未包含 head `noscript`，因此既有真实样本未暴露；但这是通用原文读取契约，合法 HTML 可触发，与原 D3 同类。
- **建议改法和验证点**：将 `"noscript"` 加入 `_HEAD_CONTENT`，使 head 在 `noscript` 起点不闭合；补 public runtime 回归：分别覆盖省略 `</head>` 与显式 `</head>` 的 head `noscript`，断言 `noscript.parent == head.opening`、`body.parent == html.opening`、`parse_status=complete`、无 `unmatched_closing_tag`；同时保留现有 head/body、colgroup、optgroup、ruby、dt/thead partial 用例。修复后重跑受影响原文测试与 pyright。
- **修复风险（低/中/高）**：低（仅补充 head 内容集合，不改其它闭合规则；需确认 `<noscript>` 在 body 场景无行为变化）。
- **严重程度（低/中/高）**：中。
