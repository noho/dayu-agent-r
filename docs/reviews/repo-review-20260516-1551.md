### 1-CRITICAL-engine_ingest 未处理异常导致 Run 终态被错误推进为 LOST

- **入口/函数**: `EngineEventIngestor._close_active_cancel()` → `_required_payload_text()`
- **文件(行号)**: `dayu/host/engine_ingest.py:677-679`
- **输入场景**: Engine 返回 `RUN_CANCELLED` event，Host 查到的 `RUN_CANCELLING` event payload 缺少 `cancel_request_event_id` 字段
- **实际分支**: `_required_payload_text(_payload_object(cancelling), field_name="cancel_request_event_id")` 抛出 `HostDurableError("payload field cancel_request_event_id must be non-empty text")`，异常在 `_ingest_validated()` 链中无 try/except 保护，传播到 `_consume_worker_events()` 第 974 行的 `except Exception` 分支，被误判为 worker lost
- **预期行为**: 应返回 `REJECTED` diagnostic 或触发 defensive closeout，而非让异常传播导致 worker 标记为 LOST
- **实际行为**: Run/Attempt 被错误推进到 LOST 终态而非 CANCELLED
- **直接证据**: `engine_ingest.py:677-679` 使用 `_required_payload_text`（会抛异常），而防御性做法应使用 `_optional_payload_text` + None 检查；`engine_ingest.py:974` 的 `except Exception` 分支无差别处理所有异常为 worker lost
- **影响**: 数据正确性问题——合法的 RUN_CANCELLED 事件因 RUN_CANCELLING payload 结构问题导致 Run 进入错误的终态
- **建议改法和验证点**: 将 `_required_payload_text` 替换为 `_optional_payload_text` + 防御性判断；若字段缺失返回 rejected diagnostic，不走 LOST 路径
- **修复风险**: 低
- **严重程度**: CRITICAL

### 2-CRITICAL-durable `_is_busy_or_locked` 遗漏 WAL 模式下的扩展错误码

- **入口/函数**: `_is_busy_or_locked()` / `run_write()` retry loop
- **文件(行号)**: `dayu/host/durable/transaction.py:358-366`
- **输入场景**: WAL 模式下，`BEGIN IMMEDIATE` 因 WAL recovery 或 snapshot 原因触发 `SQLITE_BUSY_RECOVERY (261)` 或 `SQLITE_BUSY_SNAPSHOT (517)`
- **实际分支**: `code in (sqlite3.SQLITE_BUSY, sqlite3.SQLITE_LOCKED)` 即 `code in (5, 6)`，扩展码 261/517 不命中，走 `raise durable_error from exc`
- **预期行为**: 所有 busy/locked 子类型都应收敛为重试
- **实际行为**: WAL 子类型不被识别为 busy，抛出通用 `HostDurableError` 而非 `HostTransactionRetryExhaustedError`
- **直接证据**: Python 3.11 `sqlite3.Error.sqlite_errorcode` 返回扩展错误码；`SQLITE_BUSY_RECOVERY = 261`, `SQLITE_BUSY_SNAPSHOT = 517`
- **影响**: 长运行进程中 WAL checkpoint 冲突时写事务不重试直接失败，上层可能做出错误的重试放弃决策
- **建议改法和验证点**: 使用 `code & 0xFF` mask 出基础码后再比较
- **修复风险**: 低。SQLite 保证扩展码低 8 位始终等于基础错误码
- **严重程度**: CRITICAL
