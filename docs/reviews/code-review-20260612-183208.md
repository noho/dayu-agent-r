## 逐项审查

### 1. Durable memory snapshot integrity classifier 是否 read-only / direct evidence

**结论：PASS。**

`inspect_memory_snapshot_integrity(transaction)` 位于 `dayu/host/durable/memory.py:500-527`，是只读 classifier：

- 只执行 SELECT 查询（`_memory_snapshot_integrity_rows` 和 item kind scan），不执行 INSERT / UPDATE / DELETE。
- 返回 `tuple[MemorySnapshotIntegrityIssue, ...]`，不修改任何 SQLite row。
- 五类 failure kind 均基于直接证据：
  - `invalid_json`：`json.loads(snapshot_json)` 抛出 `JSONDecodeError`。
  - `schema_mismatch`：`conversation_memory_snapshot_from_json_value` 抛出 `TypeError / ValueError`。
  - `digest_mismatch`：`calculate_memory_snapshot_digest(snapshot)` 与 row 列值不匹配。
  - `unsupported_item_kind`：item row 的 `item_kind` 为旧 `verified_fact` 或不在 allowed set。
  - `storage_read_failed`：`sqlite3.Error` 或 row identity 字段读取异常。
- scan 级失败被 catch 并返回 `snapshot_id=None` 的 `storage_read_failed` issue，不会向调用方抛出异常。
- `manual corruption` 不作为独立 failure kind；手动 SQL 修改导致的损坏会被上述五类捕获——plan 中的声明与实现一致。

### 2. run_storage_maintenance 是否仍 operator-facing explicit maintenance 且 no silent rebuild / overwrite / quarantine

**结论：PASS。**

`run_storage_maintenance` 位于 `dayu/host/storage_maintenance.py:248-317`：

- 默认 dry-run，不删除文件或 row。
- `reclaim_orphan_artifacts=True` 只回收 orphan artifact 物理文件，不删除 SQLite row。
- `inspect_memory_snapshot_integrity` 的结果通过 `read_state.memory_snapshot_integrity_issues` 传递到 `HostStorageMaintenanceResult`，只读不写。
- 没有 quarantine table、没有 rebuild 入口、没有 overwrite 逻辑。
- checkpoint 使用独立 durable connection，不在 command transaction 内执行。
- 设计真源 `docs/host/design.md:1201` 明确记录："maintenance 不删除任何 SQLite row，不 quarantine / rebuild / overwrite memory snapshot，不处理 audit JSONL / tool-trace JSONL，不执行 VACUUM，也不启动 scheduler。"

### 3. Public result / export / json 是否自解释不泄漏 payload

**结论：PASS。**

- `MemorySnapshotIntegrityIssue.json_value()` 返回 `{failure_kind, message, snapshot_id, session_id, consumer_id, policy_digest, checkpoint_event_sequence}`，全部为 operator 可读的短字段。
- `failure_kind` 使用 `StrEnum.value`（如 `"invalid_json"`），自解释。
- `message` 是短错误摘要（如 `"memory snapshot JSON is invalid: ..."`），不包含 snapshot JSON 内容、prompt 或 tool payload。
- `HostStorageMaintenanceResult.json_value()` 将 `memory_snapshot_integrity_issues` 序列为 JSON object 列表，key 名自解释。
- `MemorySnapshotIntegrityIssue` 通过 `dayu/host/__init__.py` 导出到 `dayu.host` 包根命名空间，`test_package_exports.py` 的 `EXPECTED_STORAGE_MAINTENANCE_EXPORTS` 已包含 `"MemorySnapshotIntegrityIssue"`。
