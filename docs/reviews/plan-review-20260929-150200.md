## Findings

### 1-未修复-低-usage→public 投影的 owner 与 hint 承载未钉死
- **位置**: §最小设计与唯一 owner 第 5 项（typed 错误与文案只在各自 owner 投影，plan 第 57 段）。
- **问题类型**: 契约缺失 / 语义 owner 边界含糊。
- **当前写法**: “admission 违反以对应 `FinsUploadUsageError` 表达，由 `ingestion_runtime.py` 的精确 usage→public 映射产生同码 `FinsUploadFailureReason(kind=USAGE, code=...)`”；随后“实施须由 Fins usage→public reason 唯一投影提供 target 专用 hint，tool 的 typed usage 分支消费这个投影的 message/hint，不在 tool 维护第二张 code→hint 表”；并注明“现有 `FinsUploadUsageFailure` 只有 code/message”。
- **反例/失败场景**: 该“ingestion_runtime.py 的精确 usage→public 映射”当前并不存在——全 `dayu/` 只有 `upload_failure.py` 构造 `FinsUploadFailureReason`（17 处全在该文件），`ingestion_runtime.py` 只有 `_USAGE_MESSAGES`/`fins_upload_usage_failure` 产生 `FinsUploadUsageFailure`（code/message，无 hint 字段），`FinsUploadFailureCode` 尚无 target 码。实施 Agent 找不到该映射时可能：(a) 在 `ingestion_runtime.py` 新建 `FinsUploadFailureReason` 构造点，与 failure owner 的构造点分叉；(b) 在 tool 里按 code 自拼 hint，恰好违反本段“不在 tool 维护第二张 code→hint 表”；(c) 给 `FinsUploadUsageFailure` 加 hint 后在多处各自投影。三者都触发 AGENTS.md 语义所有权违约，留到 deepreview 阶段返工。
- **为什么有问题**: plan 把一个待新建的投影写成既有映射的口吻，且未钉死唯一投影所在 owner 与 hint 的承载类型；与本段自己的“只在各自 owner 投影”“唯一投影”要求存在执行歧义。
- **直接证据**: `ingestion_runtime.py:707-741`（`FinsUploadUsageFailure` 仅 code/message）、`:1027-1097`（`_USAGE_MESSAGES`/`fins_upload_usage_failure`，产物是 usage failure 而非 `FinsUploadFailureReason`）、`upload_failure.py:37-54`（`FinsUploadFailureCode` 无 target 码）、全仓 `FinsUploadFailureReason(` 构造仅在 `upload_failure.py`、`upload_tools.py:117-124`（`str(exc)`+通用 hint）。
- **影响**: 实施 Agent 生成错误归属的映射/第二张 hint 表；typed 错误与文案双真源；tool/Fins 投影再次漂移（正是 F11/F4 已裁决过的问题类别）；deepreview 返工。
- **建议改法和验证点**: plan 钉死唯一投影的 owner 与承载：建议 `upload_failure.py` 新增 usage→public reason 唯一构造器（消费 `FinsUploadUsageFailure`/usage owner 的 message 与 hint 真源），`ingestion_runtime.py` 只产 usage fact，tool 只消费该投影的 message/hint；或明确反向选择并说明 `upload_failure.py` 不再新增构造点。同时明确 hint 承载（扩展 `FinsUploadUsageFailure` 字段，或由唯一投影直接给出 `retry_hint`）。验证点：owner 测试锁“target 三码的 `FinsUploadFailureReason` 构造点唯一、message/hint 同源、tool 无 code→hint 表”。
- **修复风险（低/中/高）**: 低。
- **严重程度（低/中/高/严重）**: 低。
