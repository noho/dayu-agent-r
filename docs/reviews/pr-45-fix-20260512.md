   handoff 明确指示 "do not restore README tests"。README 接口事实漂移
   守护属于更高层 documentation governance 选择，由 controller 后续单独
   评估，不在本次 fix scope。Residual risk 保留。

   设计选择，非 bug"，handoff 明确拒绝改动。Cancelled outcome 投影继续
   不携带 `meta`。
3. **不恢复 `docs/{engine,host}/design.md` 的 truth-source 声明**：
   handoff 明确拒绝。1455-Residual #3 的语义改在 README 内补充
   design.md 引用属于 documentation governance 决策，不在本次 fix scope。
4. **事件顺序测试（1456-#3）**：handoff 未列入控制器接受清单；属于
   后续 test enrichment 工作，本轮不实施。Residual risk 保留。

   `run_messages.finally` 通过 `_close_runner_once` 幂等收口，无运行时
