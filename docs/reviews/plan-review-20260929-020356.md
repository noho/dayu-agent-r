1. **F1 修复：七类优先级是否与当前 CLI 解析代码精确对齐**——成立。当前 `_normalized_text_tuple`（`dayu/cli/commands/fins.py:1150-1175`）对每个原始值按逗号拆分、strip、空项抛 `_EMPTY_FORM_MESSAGE`；`_single_optional_form`（:1177-1190）委托它并在归一化后 >1 项时抛 `_MULTIPLE_MATERIAL_FORMS_MESSAGE`。据此逐类核对 plan 的七类表：缺值（`values is None`）→ `None` → owner `MISSING_MATERIAL_FORM_TYPE`；单值 `""`/`"  "` → plan 规则（恰一个原始值、不含逗号、`strip()==""` → 原样透传）到 owner，同码；单值 `","`（`["",""]`）、`" ,"`（`[" ",""]`）、`"A,"`（`["A",""]`）均含逗号走共享解析器空项拒绝 `_EMPTY_FORM_MESSAGE`；单值 `"A,B"` 先拆两项再由 `_single_optional_form` 报 `_MULTIPLE_MATERIAL_FORMS_MESSAGE`。plan 的判定谓词（单值 ∧ 不含逗号 ∧ strip 空）与"其余输入原样调用 `_normalized_text_tuple()`"是完备且互斥的划分，实现落点唯一（只改 `_single_optional_form`，不改共享 helper、`_single_batch_material_form`），与裁决 F1 的修复语义逐字一致。
