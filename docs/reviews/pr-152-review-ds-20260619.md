## 3. Findings

### 001-低-LLM evidence source filter constants duplicated across two modules

- **位置**: `dayu/host/compact_pipeline.py:76-84` and `dayu/host/run_input.py` (WU-CM-14 addition)
- **问题类型**: 最佳实践偏离
- **当前代码**: `_INTERNAL_EVIDENCE_SOURCE_PREFIXES` (7 string constants) defined in both `compact_pipeline.py` (used by `_message_from_material_block` for ordinary branch) and `run_input.py` (used by `_fallback_message_from_material_block` for fallback branch).
- **为什么有影响**: 如果未来需要新增/修改内部前缀，需要同步两处。
- **为什么不影响 merge**: (a) 7 个短字符串常量，变更概率极低；(b) ordinary 与 fallback 渲染路径有意独立（plan §6.3/6.4）；(c) 合并到 shared helper 需要新增跨模块依赖，在当前架构下反而增加耦合。
- **建议**: 不修改。如果未来需要第三次复制，再提取到 compact_material.py 或 shared constants 模块。
- **严重程度（低）**: 不影响正确性、安全性或可维护性。
