## Adversarial failure pass / Ownership pass / Overcoupling pass

- Adversarial：空查询 vs 纯未知严格区分（前者 succeeded/0 计数，后者 failed+UNKNOWN 保留）；负数/bool 计数拒绝；240/10/4096 边界极值；取消竞态（原子双投影、既有终态幂等、启动前取消 `{}`）；收口失败不清 A；畸形 unknown JSON（缺键/null 漂移/说明漂移）拒绝；重复请求/已终态再推进原样返回；唯一突破面即 Finding 1 的 CLI 显示注入（合成实证）。
