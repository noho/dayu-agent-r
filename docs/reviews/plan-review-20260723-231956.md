## 4. Architecture boundary review

### 4.1 Layering

Plan 严格遵守 Host-only boundary：
- `context_anchor.py`（新增）不进入 Host public API，Service/UI 不得 import
- `ContextSizingResult` 是 Host-only sizing truth，public 投影通过 `HostContextUsageView`（仅含 7 个 public 字段）
- Service `EntrypointContextUsage` 只做 typed pass-through 和 enum mapping，不重算
- Engine 不新增 Host-budget 语义

**结论**: 无 layer violation。

### 4.2 Dependency direction

- `context_anchor.py` 接收 `HostTransaction` + `EventLogStore` 作为显式参数（stateless，不持有 singleton/cache）
- `context_budget.py` → `context_anchor.py`（单向，sizing 消费 anchor resolution）
- `dispatch.py` → `context_budget.py`（单向，dispatch 消费 sizing result）
- `memory.py` → `compact_payload.py`（单向，memory 消费 typed source boundary）
- `run_input.py` → `memory.py`（单向，RunInput 消费 typed memory view）
- 无反向依赖、无循环

**结论**: 依赖方向正确。

### 4.3 Public contracts

- `HostContextUsageView`: 7 个字段全部 public，predicted/窗口/basis_points/thresholds/method/pressure。不含 anchor refs/raw usage/policy internal refs
- `EntrypointContextUsage`: 同形但独立类型（Service 不 import Host DTO）
- `HostActivityKind.CONTEXT_USAGE` + optional `context_usage` field（非 context activity 时为 None）
- manifest v2 `sizing_snapshot`：strict validation，拒绝 v1/缺字段/unknown fields/partial

**结论**: Public contract 边界清晰，typed projection 不泄漏内部实现。

## 5. Execution semantics review

### 5.1 State transitions

Plan §5.3 "ordinary pre-start 的线性时序" 给出 4 个完整时序路径：
1. policy missing → manifest(unavailable) → start（无 sizing fact）
2. ordinary soft/hard → fact → compact/block（无 manifest/Attempt identity）
3. ordinary allow → manifest → fact → RUN_STARTED → ATTEMPT_STARTED
4. post-compact/fallback → 同上但 stage 不同

CAS miss rollback 方案（§5.6）覆盖两类失败：
1. Precondition miss → private `_StartCandidateCasMissRollback` → caller 转为 "无 dispatch"
2. Low-level `CAS_LOST` → `HostDurableError` 传播（不改 transaction runner）

**验证**: 状态转换完整、有序、可回滚。零孤立 manifest/fact 的保证通过 "同 transaction rollback" 实现。

### 5.2 Idempotency

Canonical `CONTEXT_BUDGET_EVALUATED` 使用 deterministic identity（run_id + cursor + digest + stage + policy + estimator），同一 decision replay 复用既有 row，矛盾结果 fail closed。

**验证**: Idempotency 设计正确。

**验证**: Recovery 边界清晰，不信任可伪造源。
