## Findings 摘要

### 严重（4 项）

**F1 — SSE 流式重试导致事件层数据重复**
- 位置：`dayu/engine/runners/openai/runner.py:285-299`
- 触发：SSE 流已产出部分事件后网络中断 → `_AttemptFailedRetriable` → 重试 → 两段事件拼接
- 影响：content_chunks 重复/乱序，tool_calls 可能被覆盖，LLM context 注入错误数据
- 修复方向：`_call_impl` 加 `_has_yielded` 标志，已产出事件后不再重试

**F2 — SSE 与非流式 finish_reason 处理不一致**
- 位置：`non_stream_parser.py:317-318` vs `sse_parser.py:545-549`
- 触发：provider 返回 `finish_reason=stop` 且携带 tool_calls
- 影响：非流式强制覆盖为 TOOL_CALLS（成功），SSE 保留 provider 原始 stop → Agent 层检测到 mismatch → 不可恢复失败
- 修复方向：SSE `_finalize_success` 中当 `_tool_calls_seen` 时强制 finish = TOOL_CALLS

**F3 — `reset_minimal_read_model_projection` 无 consumer 隔离**
- 位置：`dayu/host/durable/read_model.py:280-301`
- 触发：多 consumer 场景下任一 consumer 调用 reset
- 影响：`host_session_timeline_items` 和 `host_run_results` 无条件全量 DELETE，破坏所有 consumer 数据
- 修复方向：按 consumer_id 级联删除（参考 `reset_conversation_memory_projection` 正确做法）

**F4 — `RuntimeFileLock.__exit__` release 失败后实例死锁**
- 位置：`dayu/runtime/filelock.py:183-201`
- 触发：`token.release()` 抛异常（I/O 错误）→ `_active_token` 未置 None → `released` 保持 False
- 影响：下次 `acquire()` 永久抛 `RuntimeFileLockError("already active")`
- 修复方向：`__exit__` 用 `try/finally` 确保 `_active_token = None`

### 高（9 项）

**F5 — `ToolResultFailure` 缺少 `__post_init__` 空值校验**
- 位置：`dayu/contracts/tool_result.py:54-69`
- 影响：`error=""` 和 `message="  "` 静默通过，下游无法辨识错误

**F6 — `ToolResultMeta` 缺少时序一致性校验**
- 位置：`dayu/contracts/tool_result.py:26-37`
- 影响：`started_at > finished_at` 和空 `tool_name` 通过

**F7 — SSE `_handle_chunk_object` 静默吞非 dict choice**
- 位置：`dayu/engine/runners/openai/sse_parser.py:309-318`
- 影响：非 dict choice 仅 warning → 最终空 content + STOP，上游无感知

**F8 — Agent `_make_terminal_failed` 不关闭 Runner**
- 位置：`dayu/engine/agent.py:2086-2097`
- 影响：与 `_make_cancelled_terminal_with_close` / `_make_suspended_terminal_with_close` 不一致，资源延迟释放

**F9 — `ensure_projection_checkpoint` TOCTOU 竞态**
- 位置：`dayu/host/durable/projection.py:117-135`
- 影响：并发初始化 consumer checkpoint 时 `HostUniqueConstraintError` 未捕获

**F10 — schema 无 migration 策略**
- 位置：`dayu/host/durable/schema.py:25, 932-956`
- 影响：版本号升级后旧 DB 完全打不开，需外部编排

**F11 — Dispatch 双异常孤儿 Run**
- 位置：`dayu/host/dispatch.py`（`_consume_worker_events`）
- 影响：ingest 和 close_worker_lost 同时失败 → Run 保持 RUNNING 无 worker

**F12 — `run_read` 使用 `BEGIN DEFERRED`**
- 位置：`dayu/host/durable/transaction.py:267-289`
- 影响：误执行 DDL 时隐式 COMMIT，违反 read-only 契约

**F13 — `await_or_cancel` 同时完成时 result 丢失**
- 位置：`dayu/runtime/cancellation.py:128-136`
- 影响：target 和 cancel 同 tick 完成时 target 返回值被丢弃
