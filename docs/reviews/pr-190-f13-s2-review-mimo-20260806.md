**severity:** informational
**file:line:** `tool_trace.py:721-732`

### F8: `ToolTraceCompactorResponseSummary.accepted_evidence_facts` 默认 `()` — ACCEPTED（附建议）

**severity:** low
**file:line:** `tool_trace_analysis_contracts.py:484`

**裁决:** 默认 `()` 不违反 fresh public contract，不会使生产遗漏。

**理由:**
1. 生产唯一构造路径 `tool_trace_analysis_rules.py:336` 显式传递 `response.accepted_evidence_facts`，默认值从未生效。
2. `__post_init__` 对 tuple 元素类型执行 `_require_contract_tuple` 校验，对 ATTEMPT_REJECTED 执行空 tuple 校验。

4. 测试中 ATTEMPT_REJECTED 构造显式传 `accepted_evidence_facts=()`，未依赖默认值。

**建议（非阻塞）:** 若后续新增 `ToolTraceCompactorResponseSummary` 构造路径，可考虑移除默认值强制显式传参，与 `ResolvedCompactorResponseIdentity`（无默认值）保持一致。当前不改。
