## 3. Findings

### 1-未修复-低-P0-B ②向量入口文档与 schemaRef 形态未钉死，按字面构造会撞 Docling `Type.INSTANCE` 硬拒绝并可误归因
- **位置**: 计划 §5 P0-B「另做两个**相互独立**的自包含合成向量：…② 合法 XSD 的 `xs:annotation/xs:appinfo` 中放置绝对 `linkbaseRef` → catalog 映射的包内 linkbase，不放在 instance」及其后「才分别运行 Docling Path/Stream」。
- **问题类型**: 不可直接实施 / 测试缺口（规格歧义导致误归因风险；与 PR4-F1 同类的残余）。
- **当前写法**: ②只钉了绝对 `linkbaseRef` 的宿主（合法 XSD 的 appinfo、不放 instance），但没有写：Docling/Arelle 运行的**入口文档**是什么；若入口是 instance，其 `schemaRef` 以何种形态（相对→同根散文件 XSD，还是绝对→catalog 映射包内 XSD）到达宿主 XSD；宿主 XSD 本身在包内还是同根散文件。「不放在 instance」预设了 instance 存在，但其形态留白。
- **反例/失败场景**: 实施者按字面把②构造成「仅 XSD」输入：Arelle 对 schema 入口 `--validate --validationExitCode` 可 exit 0（合法性门槛通过），随后 Docling Path/Stream 在 `xbrl_backend.py:175-176` 因 `model.modelDocument.type != Type.INSTANCE` 抛 `ValueError("Document is not an XBRL instance")` → `DocumentLoadError`；按计划「任何向量若显示组合布局不可达，停止该接口承诺并以源码/原始输出回 plan/fix」，这会被记成「绝对 linkbaseRef 经 catalog 映射不可达」——把**输入形态错误**误归因为**映射机制不可达**，正是 PR2-F1/PR4-F1 反复要防的误归因模式在②上重现；且白烧一轮探针。
- **为什么有问题**: ②是绝对 `linkbaseRef` catalog 映射可用性的唯一机制证据载体（PR3-F2/PR4-F1 的验收对象），其证据链必须与混合图/①同强度防误归因；「若合法性未通过先修样本」的总规则只覆盖合法性失败，覆盖不了「合法性过、Docling 因入口形态拒绝」这一支。
- **直接证据**: 计划 §5 P0-B ②原文（仅描述 linkbaseRef 宿主，无入口文档/schemaRef 形态）；Docling 2.127.0 `xbrl_backend.py:175-176` `if model.modelDocument.type != Type.INSTANCE: raise ValueError("Document is not an XBRL instance")`（本机真实源码实读）；同文件 `:166-171` `modelManager.load(str(instance_path), taxonomyPackages=zip_paths)` 以单一路径为入口。
- **影响**: 探针循环浪费 / 「绝对 linkbaseRef 映射不可达」结论不可信 / 组合布局接口被错误停止或错误放行 / goal 3 证据链被污染。
- **建议改法和验证点**: 把②改写为完整输入形态，例如「② 自包含合成输入：instance + 同根（或包内）合法 XSD，instance 的 `schemaRef` 以〔相对→同根散文件 XSD / 绝对→catalog 映射包内 XSD，二选一并明写〕到达宿主 XSD，宿主 XSD 的 `xs:annotation/xs:appinfo` 中放绝对 `linkbaseRef` → catalog 映射的包内 linkbase，linkbaseRef 不放 instance」；并可加一句「Docling 侧每份输入的入口都是 instance 文档（Docling 拒绝非 instance 入口）」。验证点：P0-B 产物中②的 Arelle 合法性原始输出显示其入口为 instance 且验证含 linkbase 加载，Docling 结果只用于映射/读取记录，不用于证明合法性。
- **修复风险（低/中/高）**: 低（文本定约，不改产品）。
- **严重程度（低/中/高/严重）**: 低。

### 2-未修复-低-无 typed 真实正样本验收路径未绑定「受控支持范围」声明，与裁决 F02-PR-F2 要求有文本差距
