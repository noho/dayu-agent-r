## Fix Summary

- Added `dayu/tools/web/web_cancellation_text.py` as the Web tool package source-of-truth for cancellation hint text.
- Updated `dayu/tools/web/web_tools.py` pre-lock, post-lock, search-provider-cancel, fetch-cancel, and fallback-cancel paths to use the shared business-readable hint.
- Updated `dayu/tools/web/web_search_providers.py` cancellation checkpoint to use the same hint.
- Changed Web callable exception handling to project the shared hint instead of trusting exception-provided hint text at the LLM-facing `host_cancelled_outcome()` boundary.
- Updated `tests/tools/web/test_web_tools_provider.py` to assert the shared hint and to fail on `host cancelled`, `Host cancelled`, or `continue_without_web` in cancellation outcome text.
- Removed stale `_PAYLOAD_FIELD_EVIDENCE_KIND` constants from `dayu/host/compact_material.py` and `dayu/host/run_input.py`.

## Owner Boundary

- Web cancellation hint first producer: Web tool callable / search provider cancellation checkpoint.
- Validator: Web provider tests and controller residual scan.
- Durable / projection owner: `ToolCancelledOutcome` generated by `host_cancelled_outcome()`.
- LLM-facing projection: tool result message/hint consumed by the model.

The fix is placed at the producer and final projection boundary. It does not mask the issue downstream in tests or display code.
