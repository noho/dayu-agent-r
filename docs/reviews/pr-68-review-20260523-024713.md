## Residual Risk

- **`_NeverCancelledToken`**: compaction LLM 调用使用该 token 阻止 session 关闭时的即时取消。受 compactor runner timeout 和 stale output checks 约束，但应由后续 Host runtime cancellation hardening 处理。
- **rebuild 无独立 timeout/backoff**: `rebuild_conversation_memory_projection` 无专用超时策略。当前路径正确性安全（避免 Run 失败），未来应添加 observability 和 retry budgeting。
- **Test gap**: 缺少 `_build_run_input_with_lag_repair` 重试仍抛 `SNAPSHOT_LAG_OVER_THRESHOLD` 后返回 `"skipped"` 的测试路径。当前只测了 rebuild+retry 成功路径。这是低概率边界情况，但属于安全路径的测试覆盖缺失。
- **`result_preview` 对高度嵌套工具结果**: canonical JSON 截断到 1200 字符，高度嵌套结构可能截断关键信息。未来可能需要 tool-provider-owned summaries。
- **`catch_up` 失败 → rebuild 路径**: `_catch_up_memory_projection_before_worker` 中 rebuild 失败会以 `HostDurableError` 传播到 `_start_worker` 的 generic exception handler，导致 terminal closeout。这是基础设施失败的合理行为，但不同于 lag repair 的 "skipped" 路径。
