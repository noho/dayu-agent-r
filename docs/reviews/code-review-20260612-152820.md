2. **Label validation 字段路径记法与 parser 路径记法不完全一致**
   - 严重程度：低
   - 说明：`_validate_vnext_candidate_source_labels` 中的 `field_name` 参数使用 `f"evidence_backed_facts[{index}].evidence_labels"` 格式（`llm_compaction.py:870-871`），而 parser 使用 `_item_path` + `_field_path` 生成 `evidence_backed_facts[0].evidence_labels` 格式。两种记法产出的路径语义相同（`[index]` 后接 `.field`），且 label validation 错误消息中的路径仍然业务可读。不影响正确性。
   - 建议：后续 cleanup 时可统一使用 `_item_path` + `_field_path`，但不是必须。

3. **`schema_version` 错误消息不含脱敏后的实际值**
   - 严重程度：低
