### 1. Commit-time backup 已用 explicit lstat，ENOENT-only missing

**结论：PASS**

`_commit_batch_with_publication_guard(...)` 第 769–774 行：

```python
target_stat = self._lstat_optional_storage_path(
    state.target_ticker_dir,
    action="检查 commit backup target ticker directory",
)
if target_stat is not None and not stat.S_ISDIR(target_stat.st_mode):
    raise ValueError("commit backup target ticker root 必须为非 symlink 目录")
if target_stat is not None:
    self._replace_directory(state.target_ticker_dir, state.backup_dir)
```

`_lstat_optional_storage_path`（第 1110–1134 行）的语义：
- `os.lstat` 成功 → 返回 `stat_result`
- `errno.ENOENT` → 返回 `None`（唯一 missing 判定）
- `EACCES`/`EIO`/其它 operational OSError → `_raise_path_free_error`（fail closed）

commit backup 路径在首次 `_replace_directory` 前完成全部判定，符合要求。
