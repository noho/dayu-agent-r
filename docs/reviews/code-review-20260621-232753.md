### 残余小项（非 blocker）

#### R1-残余-低-`_missing_request_id_response_or_none` 对非 object body 返回 None 而非拒绝

- **入口/函数**: `handle_wait_callback_completion` → `_missing_request_id_response_or_none`
- **文件(行号)**: `dayu/service/wait_callback_endpoint.py:259-261`
- **输入场景**: request body 为非 object（如 `[1,2,3]`），同时 header 无 `x-dayu-callback-request-id`
- **实际分支**: `_json_object_or_none` 返回 None → 函数返回 None → 不拒绝 request_id 缺失 → 继续到 `_completion_envelope_from_request` → `_require_json_object` 抛出 TypeError → 被 catch 为 `malformed_payload`
- **预期行为**: 最终结果正确（400 malformed_payload），但 `_missing_request_id_response_or_none` 名义上是"pre-check request id"，实际对非 object body 跳过了检查
- **影响**: 无。非 object body 路径最终被 `_completion_envelope_from_request` 正确拒绝。此为防御深度问题，非行为缺陷
- **建议改法**: 无需修复。若需提高防御深度，可在此处也对非 object body 返回 malformed_payload，但收益极小
- **严重程度（低）**: 残余风险，非 blocker
