**裁决要求**：`shutil.copytree(..., symlinks=True, ignore_dangling_symlinks=False)`，禁止 follow symlink；测试证明 staged tree 保留 symlink shape，随后 no-follow validation 拒绝。

  ```
  显式调用
  `shutil.copytree(public_config, staged_config_root, symlinks=True,
  ignore_dangling_symlinks=False)` 把用户 config 复制到 staged config，保留用户
  额外内容及 symlink/dangling symlink 的原始 shape；不得使用默认
  `symlinks=False` follow symlink，也不得把 workspace 外部目标内容复制成 staged
  regular file；
  ```
- S4 exact changes 第 1 点（line 820-825）：同样明确 `symlinks=True, ignore_dangling_symlinks=False` 与禁止 dereference。
- S4 tests：
  - "用户 config 内指向 workspace 外部 regular file 的 symlink 经 copytree 后在 staged tree 仍是 symlink shape，外部目标 bytes 未被复制成 regular file，随后 no-follow validation fail closed"（line 854-856）
  - "dangling symlink 同样保留 shape 并失败"（line 856）
  - "root/nested symlink、dangling、FIFO/reparse 全 mode reject"（line 862）

**代码事实**：当前生产代码 `init_workspace.py:822-826` 已使用 `shutil.copytree(..., symlinks=True)`。plan 在此基础上增加显式 `ignore_dangling_symlinks=False`（即 Python 默认值），确保实施 Agent 不会误改为 `True` 而静默跳过 dangling symlink。

**结论**：✅ R01 已正确关闭。参数约束完整，测试覆盖 dereference 与 dangling symlink 两条路径。

### R02 — cleanup no-follow stat shape

**裁决要求**：shape 必须从同一次 no-follow identity/stat 的 mode 通过 `stat.S_ISREG` / `stat.S_ISDIR` 判定；禁止 `Path.is_file()` / `Path.is_dir()` 或其它 follow-symlink API。

**plan 现状**：

- §6.5（line 439-446）：
  ```
  expected shape 的产生、actual shape lock 与 quarantine 后 shape recheck
  都只能读取同一次对应 no-follow identity/stat 结果的 `PathIdentity.mode`，分别通过
  `stat.S_ISREG(mode)` / `stat.S_ISDIR(mode)` 判定；不得使用
  `Path.is_file()`、`Path.is_dir()` 或任何 follow-symlink API。
  ```
- §6.5 cleanup dispatch（line 447-467）：固定 6 步顺序，第 3 步明确 `stat.S_ISREG` / `stat.S_ISDIR` 判定，symlink/reparse/special fail closed；第 6 步 `REGULAR_FILE` 分派使用 `os.unlink(quarantine)`（不跟随目标，无 `missing_ok`）。
- S4 tests：明确要求 "quarantine recheck 中 symlink-to-regular-file 与 symlink-to-directory 的 no-follow mode 都不满足 `stat.S_ISREG` / `stat.S_ISDIR` expected shape，证明 cleanup 不会 follow target"（line 868-871）。

**代码事实**：当前 `_path_identity` (line 1420) 使用 `os.stat(path, follow_symlinks=False)`。plan 要求 shape 判定复用同一次 stat 结果的 `mode` 字段，不重复 stat、不使用 follow-symlink predicate。`_PrivatePathShape` 枚举值 `REGULAR_FILE` / `ORDINARY_DIRECTORY` 的判定规则已精确绑定到 `stat.S_ISREG(mode)` / `stat.S_ISDIR(mode)`。

**结论**：✅ R02 已正确关闭。shape 判定链（identity → mode → stat.S_ISREG/S_ISDIR → _PrivatePathShape）完整且无可 follow-symlink 的旁路。
