- **Source**: AgentMiMo F1 / AgentDS F02
- **Controller adjudication contract**:

  2. Second consecutive empty-prompt Ctrl+C exits.

  4. The pending-exit state resets when the user performs non-interrupt input activity (typing/submitting a prompt, EOF handling, or entering a running Run state).
