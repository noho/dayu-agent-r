- **测试证明**: `test_session_action_help_contains_fixed_parser_shape`（`tests/cli/test_arg_parsing.py:609+`）断言 `"--config" not in resume_help`；`test_agent_help_omits_removed_parameters` 断言 `"--config" not in interactive_help` 和 `"--config" not in prompt_help`。
- **结论**: resume leaf parser surface 不含 `--config`，help 文本与执行 contract 一致。✅

#### 2. root/command/action 三位置仍 fail closed

- **root 位置**（`--config X session resume ...`）: root parser 使用 `root_runtime_parent`（含 `--config`，`arg_parsing.py:237-238`），argparse 接受后 `config_dir` 非 None → `_reject_disallowed_explicit_config()`（`arg_parsing.py:310-314`）检测 `command_name == COMMAND_SESSION and session_action == SESSION_ACTION_RESUME` → `parser.error()` → `SystemExit(2)`。✅
- **command 位置**（`session --config X resume ...`）: session command parser 使用 `command_runtime_parent`（含 `--config`，`arg_parsing.py:260-262`），argparse 在 command scope 接受 → 同上 `_reject_disallowed_explicit_config()` 拒绝。✅
- **action 位置**（`session resume ... --config X`）: resume action parser 使用 `action_common_parent`（不含 `--config`），argparse 在 action scope 将其视为未知参数 → `SystemExit(2)`。此拒绝发生在 argparse 内部，不依赖 `_reject_disallowed_explicit_config` 的二次校验。✅
- **测试证明**: `test_agent_surfaces_reject_config_in_every_parser_position`（`tests/cli/test_arg_parsing.py:1562+`）覆盖 root-before（prompt、interactive、session resume prompt mode）、command-level（session resume interactive mode）、action-level（session resume interactive mode）六个案例，均断言 `SystemExit(2)`。
- **注意**: command-level 和 action-level 的 parametrize 案例只覆盖了 interactive mode。由于 `_reject_disallowed_explicit_config()` 按 `command_name + session_action` 判断而非按 mode，prompt-mode 的 command/action 位置同样被覆盖（command-level 由 argparse 同一入口拒绝，action-level 由 argparse 未知参数拒绝，均不依赖 mode）。此为低风险的测试覆盖间隙，不影响正确性。
- **结论**: 三个 parser 位置均 fail closed，无静默忽略。✅

#### 3. list/purge root/command/action config 正向不回归

## Adversarial Failure Pass

以下场景均沿真实代码路径走读确认：

1. **Root-before-command `--config` + Agent surface**: `dayu-cli --config X prompt hello` → root_runtime_parent 接受 → `_reject_disallowed_explicit_config` 拒绝 `command_name in (COMMAND_PROMPT, COMMAND_INTERACTIVE)` → `SystemExit(2)`。✅

4. **Session action-level `--config` + resume**: `dayu-cli session resume --config X --mode interactive` → action_common_parent（不含 `--config`）→ argparse 未知参数错误 → `SystemExit(2)`。✅
5. **Interactive `--ticker`**: `dayu-cli interactive --ticker AAPL` → argparse 未知参数错误（interactive 不含 `--ticker`）→ `SystemExit(2)`。✅
6. **Session resume interactive `--ticker`**: `dayu-cli session resume --mode interactive --ticker AAPL` → resume parser 接受（共享 parser 注册了 `--ticker`）→ `_reject_interactive_resume_ticker` 拒绝 → `CliSessionUsageError` → `EXIT_USAGE_ERROR`。✅
