**claim 由 evidence_material 或 previous_evidence_fact 直接支持**：plan 写法为 "必须由 `support_labels` 对应的 accepted `evidence_material` 或 `previous_evidence_fact` 直接支持"。直接证据：

**policy_limit 仅当前 repair feedback 明示具体 cap 后可用**：plan 写法为 "当前 repair feedback 已明确给出一个具体 cap，并且为使完整 replacement 落入该 cap 而必须舍弃它。首次请求、没有 repair feedback、或当前 feedback 没有明示具体 cap 时禁止猜测或使用"。直接证据：
- `dayu/host/context_governance.py:492-576`：`_collect_policy_issues` 使用 `MemoryProjectionPolicy` 的 item/char cap 生成 issue message，具体 cap 数值出现在 repair message 中。
