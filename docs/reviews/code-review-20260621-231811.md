## Open Questions

- `request_id` 缺失时默认为 `"missing"` 而非 `transport_rejected` 或 `malformed_payload`：当前设计把 `request_id` 视为可选审计字段，缺失时交由 adapter/authenticator 分类。这与 plan 一致（"缺失认证字段交给 adapter 分类"），但与 `wait_id`/`idempotency_key` 等必填字段的 `malformed_payload` 处理不同。如果未来 adapter 不显式检查 `request_id="missing"`，这个值会以字符串 "missing" 进入 Host envelope 和 EventLog。当前 Host adapter 测试未覆盖 `request_id="missing"` 场景，无法确认 adapter 行为。这不阻塞 Slice 2 ship，但应作为 Slice 1 adapter 补测项跟踪。
