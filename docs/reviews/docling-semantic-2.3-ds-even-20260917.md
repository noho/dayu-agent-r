## 对判定口径的观察

1. **片段-完整数字配对是判读 merged 大负值的必做步骤**：本路 3 份 merged 最负样本（-723/-549/-220）全部是基线千分位数字切片→新版合并所致。仅看 missing 列表会把「数字识别规范化」误判为「数字丢失」。
2. **乱码 token 形态新增两类**（上一轮未见）：(a) 英文字体渲染乱码——2.90 把 wingdings 类字体的英文标题识别为符号数字（'BIOGRAPHIES' → '#*0(3"1)*&4'，产生 '5034'、'1035' 等 token）；(b) 千分位片段（'301'/'955'/'419'）。两者在新版均被清除/合并，方向均为修复。
3. **merged Δ 与文档类型相关**：本路美的系季报（小文档、表格密度高）贡献了全库最负的三个 Δ；这些文档的表格数字占 token 总量比例高，千分位规范化对 Δ 的放大效应最强。
4. 与上一路一致的观察（heading 全 0/0、missing 列表不含计数、moved_to_table_ratio 为存在性命中率）同样适用于本路，不重复展开。
