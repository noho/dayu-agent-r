## 新 blocker 检查

### Filing-only identity 与 material unchanged 的可实施性

- **检查**: §6.6 table 为 `_build_original_assets()`、`_build_pending_assets()`、`_store_upload_assets()` 三个方法分别定义了 filing 和 material 的行为。filing 使用 identity helpers，material 保持 `file_path.name`。`_build_stored_file_entry()` 必须接收 `source_kind` 或等价强类型来执行分支。
- **风险**: `_build_stored_file_entry` 当前是 module-level private function，不接收 `source_kind`。需要新增参数或通过 `_PendingFileAsset` 的 `original_filename is not None` 来隐式判断。plan §6.6 要求"必须显式接收 `source_kind`（或等价的强类型 filing projection decision）"并"禁止 `getattr/hasattr`、松散 dict fallback"。
- **结论**: 可实施。`_build_stored_file_entry` 可以新增 `is_filing: bool` 参数（从 `_store_upload_assets` 的 `source_kind` 传入），或检查 `asset.original_filename is not None`（强类型 `str | None` 已足够区分）。无新 blocker。

### Fingerprint 与 asset identity 分离的一致性

- **检查**: filing fingerprint 由 `original_filename`、`sha256`、`size`、`source` 组成，排除 `name`（path identity）。material fingerprint 由 `name`、`sha256`、`size`、`source` 组成。`_build_upload_source_fingerprint()` 需要 source-kind-aware 分支。
- **风险**: 当前 `_build_upload_source_fingerprint()` 是 module-level private function，不区分 source kind。需要新增分支逻辑。
- **结论**: 可实施。`_build_upload_source_fingerprint` 可以新增 `is_filing: bool` 参数，filing 用 `original_filename` 替代 `name` 构造 descriptor。plan §6.6 明确"不新增第二套 fingerprint helper"，只在现有函数内分支。无新 blocker。

### Delete precedence

- **检查**: §6.2 冻结 precedence：`TOO_MANY_FILES` → `FILES_NOT_ALLOWED_FOR_DELETE` → `PRIMARY_NOT_ALLOWED_FOR_DELETE`。files error 在 resolve/duplicate/exists/role 前。files+primary 时 files 优先。
- **结论**: 完整且一致。无新 blocker。

### Projection fields

- **检查**: `FinsUploadFormatTextProjection` 新增 `filing_primary` 和 `upload_tool_primary`。CLI help 消费 `filing_primary`，tool schema 消费 `upload_tool_primary`。`project_fins_upload_format_text()` 由同一关键规则片段产生两字段。tests 断言同源规则。
- **结论**: 完整且一致。无新 blocker。

### Allowed tests

- **检查**: `tests/fins/test_fins_service_runtime.py` 已加入 Slice 1 allowed tests、Slice 1 pytest/pyright、Slice 4 affected validation 和 overall allowed files。该文件存在（已验证）。Slice 3 增加了 material regression tests。所有 13 个 test files 均存在（已验证）。
- **结论**: 完整。无新 blocker。
