## Residual Risk

- **God Module 技术债**: state.py、run_transition.py、config_loader.py、scene_prepare.py、host_assembly.py 五个文件都存在 God Module 问题，随着新 phase 引入更多逻辑会继续膨胀。这是架构层面需要持续治理的技术债。
- **_require_non_empty_text 全仓扩散**: 12+ 处独立定义，若未来需要修改校验行为需要逐文件修改。
- **Host 与 Engine contracts 耦合**: 当前 Host 的公共 API 表面积依赖 Engine 类型。如果 Engine contracts 发生 breaking change，Host 的 public API 会连带变更。
- **cancel_session_runs 不完整**: 对 WAITING/RECOVERING Run 的处理不完整，可能导致调用方误判 Session 状态。
- **lane.py 外层取消路径的测试覆盖**: 四个 DB 操作方法各有复杂的取消+cleanup+timeout+observer 路径组合，确认这些路径都有对应的测试覆盖是降低维护风险的关键。
- **Schema SQL 归一化校验的脆弱性**: _normalize_schema_sql 只做空白折叠，不解析 SQL。SQLite 在不同版本间可能对 CREATE TABLE 语句的内部表示做细微格式调整，升级 SQLite 版本时需验证。
- **未覆盖区域**: tests/、utils/、workspace/、constraints/、docs/ 未在本次 review 范围内。
