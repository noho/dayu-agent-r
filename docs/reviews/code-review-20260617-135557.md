### 1. watcher drain ordering 正确

`_drain_available_watcher_items` (行 765–790) 的循环顺序为：

1. `queue.get_nowait()` → `QueueEmpty` 返回 `None`
2. `_WatcherFailure` → `_record_watcher_failure` + `_emit_watcher_failure_activity` → `continue`
3. `_terminal_result_from_live_event` → terminal 非 `None` 时 **立即 return**

**直接证据**：行 783 `if terminal is not None: return terminal` 在行 785 `_emit_entrypoint_activity_from_host_event` 之前。Terminal 始终优先于 activity 投影返回，activity 不会吞掉 terminal 或 outbox fallback。

### 2. accepted run id 过滤正确

**直接证据**：行 812–813。`HostEvent.run_id` 类型为 `str | None`，`None != run_id` 为 `True`，不绑定 Run 的事件被正确过滤。测试 `test_submit_entrypoint_turn_filters_unrelated_activity` 覆盖了 `other-run` → filtered、`run-1` → passed 的场景。

**直接证据**：行 814–816。`_terminal_result_from_live_event` 中的 `seen_dedupe_keys` 和 `_emit_entrypoint_activity_from_host_event` 中的 `seen_activity_dedupe_keys` 是两个独立集合，不会互相干扰。测试 `test_submit_entrypoint_turn_deduplicates_activity_by_dedupe_key` 覆盖了重复 dedupe_key 只 callback 一次的场景。
