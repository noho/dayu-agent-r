### 3. _fins_wait_poll_adapter_registry_from_provider_configs 数据流

新增函数（host_assembly.py:1837-1868）与 `_fins_wait_activation_registry_from_provider_configs`（host_assembly.py:1801-1834）同构：

- 共享 `_fins_awaiting_registry_inputs_from_provider_configs` 汇总启用 provider 的 tool_names 与 workspace_root
- `registry_inputs is None` 时返回 `None`（无启用且进入 ToolBundle 的 Fins awaiting binding）
- `fins_awaiting_runtime is None` 时 fail fast（理论上不可达：有 inputs 必有 runtime）
- `isinstance(fins_awaiting_runtime, FinsIngestionRuntime)` 类型守卫确保 poll adapter 拥有 `poll_observation` 方法
- 使用同一个 `fins_awaiting_runtime` 构造 registry，保证 callable / activation adapter / poll adapter 共享 runtime
