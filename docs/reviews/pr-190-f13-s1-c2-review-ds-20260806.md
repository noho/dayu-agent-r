## 手工复算 retained + two-source-new 逐 fact/aggregate refs

按 checkpoint §Manual retained + two-source-new recomputation 执行确定性复算，代码路径 `derive_compact_accepted_replacement_v4` 与 `CompactAcceptedReplacementV4.canonical_evidence_refs`：

```text
boundary P1: canonical_evidence_refs = (evidence:previous-a, evidence:previous-b)
boundary E1: canonical_evidence_refs = (evidence:current-a, evidence:shared)
boundary E2: canonical_evidence_refs = (evidence:shared, evidence:current-b)

retained P1 → claim=entry.readable_text, refs=entry.canonical_evidence_refs
  = (evidence:previous-a, evidence:previous-b)

new fact support (E1, E2) → 按 boundary 序遍历 matched entries 并 extend refs
  → refs = [evidence:current-a, evidence:shared, evidence:shared, evidence:current-b]
  → dict.fromkeys → (evidence:current-a, evidence:shared, evidence:current-b)

replacement.evidence_facts = [retained_atom, new_atom]
replacement.canonical_evidence_refs = 逐 fact 逐 entry unique union
  = (evidence:previous-a, evidence:previous-b, evidence:current-a, evidence:shared, evidence:current-b)
```

与 `test_retained_plus_two_source_new_fact_has_exact_per_fact_and_aggregate_refs` assertion 精确一致。复算不读取任意单 entry、operation flat union、event ordinal 或 claim 文本反推 provenance。

## Findings

### F1 — `derive_compact_accepted_replacement_v4:1677` retained kind 双重校验

- **Severity**: info
- **File/line**: `dayu/host/compaction.py:1677`
- **Evidence**: `compact_proposal_boundary_binding_issues_v4`（line 1664）已用 `COMPACT_RETAIN_SOURCE_KINDS_V4=(PREVIOUS_EVIDENCE_FACT,)` 校验 retained labels 的 kind。若绑定通过，后续 `entry.source_kind is not CompactSourceKindV4.PREVIOUS_EVIDENCE_FACT`（line 1677）理论上不可达。该检查为 defense-in-depth 冗余。
- **Impact**: 无功能影响。作为局部不变量文档与防御层有微小价值。
- **Suggested fix**: accepted-as-is。可考虑改为 `assert` 以明确语义。
- **Verdict**: **accepted**

### F2 — `run_input_material_block` 中 `evidence_refs` 构造 fallback 到 singular `accepted_evidence_id`

- **Severity**: info
- **File/line**: `dayu/host/compact_material.py:800-805`
- **Evidence**: 当 `accepted_evidence_id is not None and not canonical_evidence_refs` 时，构造器 fallback 为 `(accepted_evidence_id,)`。`RunInputMaterialBlock.__post_init__:281-294` 在 evidence 路径上强制 `canonical_evidence_refs == (accepted_evidence_id,)`，因此 fallback 实质上不改变语义。
- **Impact**: 无功能影响。构造便利性掩盖了 `canonical_evidence_refs` 应始终显式设置的意图。
- **Suggested fix**: accepted-as-is。若未来有 lint 或 consistency pass 可移除 fallback 并强制调用方显式传入。
- **Verdict**: **accepted**

### F3 — durable parser tamper 矩阵未单独覆盖 `context_labels` 与 `omitted_coverage.source_labels` 定向篡改

- **Severity**: low
- **File/line**: `tests/host/test_context_compact_events.py:609-637`（tamper parametrize）
- **Evidence**: 当前的 tamper 测试覆盖 `claim`、`selection_labels`（未知/空）、`canonical_evidence_refs`（错误/空），但未为 `context_labels` 单独构造篡改参数。`validate_compact_proposal_replacement_binding_v4` 执行 `replacement != expected` 的完整对象相等比较，故 `context_labels` 篡改同样会被捕获——只是没有独立 test case。同样，`omitted_coverage.source_labels` 被篡改时，`_validate_committed_coverage` 的 partition/disjoint 检查会捕获，但无独立 test case。
- **Impact**: 现有测试通过 replacement 全对象相等比较间接覆盖了这些篡改，功能正确。缺少独立 case 不会导致漏检，但降低了 failure message 的针对性可读性。
- **Suggested fix**: 可接受现状。长期可在 tamper parametrize 中追加 `context_labels` 与 `omitted_coverage.source_labels` 的独立条目。
- **Verdict**: **accepted**
