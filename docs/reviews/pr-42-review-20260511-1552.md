## Findings

未发现实质性问题。

已重点核对的关键闭环：

- `HostToolRuntime.engine_visible_tool_schemas()` 只向 Engine 投影普通 `ToolSchema`，并在业务工具名与 Host framework `fetch_more` 冲突时 fail fast；framework 调用在 `execute_tool_call()` 中走普通工具调用路径，业务工具成功后才应用 Host 私有截断（`dayu/host/_tool_runtime.py:253`, `dayu/host/_tool_runtime.py:284`）。
- `RuntimeTruncateManager.apply_truncation()` 在成功工具结果返回前创建并登记 cursor，`fetch_more()` 校验 cursor、terminal run、session/run binding、TTL、scope token、limit clamp 后 single-use 消费旧 cursor，并只通过普通 `ToolCompletedOutcome` / `ToolFailedOutcome` 返回结果（`dayu/host/_runtime_truncate_manager.py:243`, `dayu/host/_runtime_truncate_manager.py:289`）。
- `ProjectionCoordinator` 对 non-required `NonTransactionalObserverSink` 先在事务外执行 sink I/O，成功后才短事务推进 checkpoint；checkpoint 失败时不推进 success position，后续 replay 依赖 trace record `idempotency_key` 去重（`dayu/host/_event_observer.py:295`, `dayu/host/_event_observer.py:373`）。
- durable memory repair 区分缺失 snapshot row、intentional empty snapshot row 与 corrupt snapshot row；坏行只返回 diagnostic，不自动覆盖，缺失行按 EventLog canonical facts 重建（`dayu/host/_conversation_memory_durable.py:315`, `dayu/host/_conversation_memory_durable.py:350`）。
- SSE 协议错误路径在 invalid JSON / non-object payload / malformed usage 后立即 `RunnerDone(ERROR)` 收口，并携带有界 partial tool-call summary，不携带 raw arguments（`dayu/engine/runners/openai/sse_parser.py:230`, `dayu/engine/runners/openai/sse_parser.py:416`）。
