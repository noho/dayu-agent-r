## Verification of Key S4 Contracts

1. **Service relay 删除**: `_ENTRYPOINT_LIVE_EVENT_BUFFER_CAPACITY`、`_WatcherFailure`、`_WatcherQueueItem`、queue/drain_task、`_drain_host_events` 全部删除。stale scan 确认无残留。
2. **Exact-five sole consumer**: `_ServiceObservationState` 实现 capacity-one slot + generation binding + exact-five closed union (`_TargetTerminal | _DeliveryInterrupted | _IteratorEnded | _CallbackFailed | _IteratorFailed`)。sole consumer 通过 `_consume_host_events` 唯一调用 `anext()`。
3. **Callback execution port**: `EntrypointCallbackExecutionPort` Protocol 定义 `invoke_activity` / `invoke_thinking`；`RuntimeDisplayController` 作为 concrete owner 实现，使用私有 `ThreadPoolExecutor(max_workers=1)` + async serial gate。
4. **Cleanup ordering**: `_close_watch_and_wait_runtime` 先 `request_stop()` → cancel consumer → await consumer → `aclose()` watcher → `mark_closed()`。`_finish_observation_result` 先 cleanup → 按 exact-five disposition 处理。
5. **Exception chain**: `_raise_primary_with_cleanup` 保持 primary identity + cleanup 作为 cause。`_raise_delivery_recovery_failure` 保持 recovery → delivery → cleanup 链。
6. **Callback shield**: `_await_shielded_callback_job` 使用 `asyncio.shield` + re-shield loop 确保 callback job 完成后才传播 cancellation。
7. **Typed overflow-only durable recovery**: `_DeliveryInterrupted` 只匹配 `HostApiErrorCode.DELIVERY_INTERRUPTED + TRANSIENT_MAILBOX_OVERFLOW`；recovery 走 `_wait_for_durable_terminal`，失败时 `raise recovery_error from delivery_error`。
8. **Terminal identity dedupe**: `seen_event_ids` 集合已删除，改用 `seen_terminal_event_ids` + `seen_dedupe_keys` 双重去重。
9. **CLI display lifecycle**: `execute_interactive_on_session` 创建 invocation 级 display controller，通过 `_run_interactive_repl` 传递，最终由 `_close_runtime_display` 关闭。
10. **README 更新**: `dayu/README.md`、`dayu/service/README.md`、`tests/README.md` 均已更新，反映 sole consumer、typed delivery interruption recovery 和新测试结构。
