- **影响**: 低。S2 的 exact changes 足够具体，但 §6 的 contract 描述可更精确。
- **建议改法和验证点**: §6 raw reader 描述改为 "非 string 抛 `ValueError`，不在 tool argument boundary 做类型折叠"。
- **修复风险（低）**: 文案微调。
