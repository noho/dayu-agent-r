## Finding F09: Semantic ownership drift 检查

**Severity**: N/A (confirmed correct)

**Propagation audit**:

Finish reason 路径：
```
Provider response choices[].finish_reason
  → OpenAI parser internal mapped finish_reason
  → RunnerDoneData.finish_reason
  → Agent _IterationState.finish_reason
  → IterationCompletedData.finish_reason
  → Host terminal/final-answer/iteration-completed preview
```
Content-completed 事件和 Host content preview 不再参与此路径。✓

Usage identity 路径：
```
Provider response header (x-request-id / x-ds-trace-id)
  → OpenAI Runner provider_request_id
  → SSE parser RunnerUsageRecordedData.provider_request_id
  → Non-stream parser RunnerUsageRecordedData.provider_request_id
  → Agent UsageReportedData.provider_request_id
  → Host USAGE_REPORTED payload.provider_request_id
  → Host UsageObservation.provider_request_id
  → Host invalid usage digest.provider_request_id
```
所有路径同源。✓

同一业务事实（finish reason、usage provider id）在 durable state、trace、audit、projection 中都从同一个 source-of-truth 派生，无 drift。

**Verdict**: pass。
