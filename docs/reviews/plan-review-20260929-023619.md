- 失败场景：S2 接通后，外部代码直调 `sec_pipeline.upload_material` 传 101 文件 → planner typed 拒绝 → 流内 catch-all → `runtime/unexpected_runtime`，与本 work unit 要消除的行为同款。
- 修复建议：plan 在 S1 范围句中显式点名三点——(a) `FinsUploadUsageCode` 扩展本 goal 的资产输入 code；(b) `FinsUploadFailureCode` 在 USAGE kind 下扩展对应 code 并更新 `upload_failure.py:199-208` 的分组完备性断言；(c) `fins_upload_failure_from_exception` 增加 planner typed error 的分类分支（或规定 planner 在 pipeline 边界以 `FinsUploadFailureError` 抛出）。三个文件均已在白名单，补上触点枚举即可。
