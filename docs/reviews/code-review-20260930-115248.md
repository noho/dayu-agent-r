- **直接证据**:
  1. 探针 A：101 对 filing 形态计划（`original-<digest>.zip`）`UploadAssetPlan(...)` 构造成功（`validate()` 通过），且 `_prepare_upload_asset_plan(source_kind=MATERIAL, selection=plan, action="create")` 返回同一对象；同样 101 对的 material 形态计划在同一契约下抛 `too_many_files`。
