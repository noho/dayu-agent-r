## 变更动机与 semantic owner 确认

DL-F15 问题真实存在且严重性判断准确。`convert_pdf_bytes_with_docling` 在 attempt 回退循环外只构造一次 `DocumentStream`；`run_docling_pdf_conversion` 对同一 callback 调用至多三次。若首档转换器关闭底层 `BytesIO` 后失败，后续 attempt 读取同一流即抛 `ValueError: I/O operation on closed file.`。

修复的 semantic owner 是 `convert_pdf_bytes_with_docling` 的 `immutable raw_bytes → per-attempt DocumentStream` 装配边界。修复放在该 owner 内，未在 Fins runner、调用方、测试夹具或异常处理层添加补偿。
