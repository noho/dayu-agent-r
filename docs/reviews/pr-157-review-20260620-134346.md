## Residual Risk

1. **`_patched_compactor_runner` monkey-patch 的维护耦合**: patch 目标 `dayu.host.llm_compaction._run_agent_request` 是私有模块函数。若 Host 内部重命名或移动此函数，smoke 会因 identity check fail-fast 而抛 `RuntimeError`（不会静默失效）。当前 smoke 是单线程 CLI 工具，不存在并发竞争。若未来 smoke 需要并行执行多个 suite，需要不同的隔离策略。

2. **Reactive suite 的 `MemoryProjectionPolicy` cap 依赖默认 floor**: `_reactive_compact_smoke_memory_policy`（line 3231-3275）假设 `selected_recent_window_turn_floor <= 4`（`_SMOKE_REACTIVE_HISTORY_GAP_ROUNDS + 1`）。若 Service 装配产出更大的 floor，会抛 `ValueError`（fail-closed）。当前 smoke 配置不受影响。

3. **Real-provider `memory-compact` 的环境依赖**: `memory-compact` 是唯一需要真实 API key 的 suite。Plan 和 PR description 均已记录此 risk，不属 WU-CM-15 scope。

4. **Fallback pressure padding 对小 context window 的适用性**: `_COMPACT_FALLBACK_PRESSURE_RESERVE_TOKENS = 160_000` 是固定常量。若小窗口模型（如 128K）成为 fallback smoke 的 execution profile，pressure 估算可能不准确。当前 smoke 使用 `standard-256k` profile，不受影响。

5. **CI/check 缺失**: GitHub Actions 未在此 branch 触发。PR description 记录了本地全部验证通过（pyright 0 errors、51 tests passed、4 suite smoke PASS）。建议在 merge 前至少运行一次 CI 或等效本地验证。
