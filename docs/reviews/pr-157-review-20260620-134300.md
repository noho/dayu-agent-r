### 1. 生产代码变更审查

唯一生产代码变更在 `dayu/host/compaction_operation.py:2062-2065`：

**变更**: `_log_rejected_attempt` 函数从条件分级（`repairable → WARNING`，`non-repairable → ERROR`）简化为统一 `WARNING`。

**语义合理性**: compact attempt rejection 是 operation 内的中间诊断事件，不是 terminal failure。Terminal failure severity 由 surrounding dispatch / engine-ingest closeout 路径负责（`CONTEXT_COMPACTION_FAILED` event），attempt-level rejection 使用 WARNING 级别是正确的 observability 分层。将 non-repairable attempt rejection 降级为 WARNING 不会掩盖 terminal error，因为 fallback dispatch 路径有自己的 failure 语义。

**测试覆盖**: `test_run_compaction_operation_logs_terminal_reject_as_warning` (line 951-978) 验证 terminal reject 只记录为 WARNING，且 `caplog` 精确匹配 logger name 和 event marker `host.compaction_operation.attempt_rejected`。
