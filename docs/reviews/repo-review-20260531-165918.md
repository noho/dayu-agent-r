## Residual Risk

1. **模块规模风险**：`dayu/host/durable/run_transition.py` (5870 行)、`dayu/host/tool_runtime.py` (5707 行)、`dayu/host/durable/state.py` (5379 行)、`dayu/host/admission.py` (4954 行) 行数极高。虽 CLAUDE.md 未明确禁止 God module，但模块内聚性随规模递减，建议关注拆分时机。
2. **SQLite 并发模型依赖**：多项 finding（event_log TOCTOU、purge precondition 距离）的安全性依赖 `BEGIN IMMEDIATE` + WAL 模式保证。如果未来引入其他存储后端或修改事务策略，需要重新评估这些路径。
3. **Purge crash-recovery 测试缺口**：purge commit 后、文件清理前进程崩溃的场景缺少集成测试覆盖（finding #3 的根因场景）。
4. **启动期异常路径测试缺口**：`open_host` 启动期异常不 flush projection 的场景缺少显式测试覆盖（finding #5）。
5. **Engine 空 content 路径测试缺口**：正常迭代中空 content 的不一致处理缺少测试覆盖（finding #7）。
6. **未审查区域**：`dayu/config/prompts/`（YAML prompt 模板）、`.github/`（CI 配置）、`utils/`（辅助脚本）未在本次审查范围内。
