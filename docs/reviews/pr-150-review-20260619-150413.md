## Findings

### 1-deferred-高-Recovery tier rejected attempts 不写入 EventLog

- **入口/函数**: `HostDispatchScheduler._execute_proactive_compaction()` → recovery loop → `_operation()` transaction
- **文件(行号)**: `dayu/host/dispatch.py:1343-1407`
- **输入场景**: proactive compaction 首次 operation 全部 rejected，进入 recovery tier 循环
- **实际分支**: `for rejected in result.rejected_attempts:` 只遍历初始 operation 的 rejected attempts；recovery tier 的 `tier_result.rejected_attempts` 被丢弃
