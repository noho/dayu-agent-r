### 新引入的确定性缩小机制

PR 150 的新缩小语义全部符合 design doc 规定的四种合法方式：

1. **Deterministic selection**：`select_compact_segment` 支持 `max_selected_size_units` 和 `max_selected_item_count` 两个独立维度；`_limit_items_by_count_and_chars` 使用 `item_cap` + `char_cap` + `floor` 做确定性选择。

2. **Whole-item keep-drop**：`_session_summary_from_accepted_event` 和 `_facts_from_accepted_event` 从 `_bounded_text()` 静默截断改为：超 char_cap 时 whole-item drop + diagnostic。`_limit_items_by_count_and_chars` 按 item 整体 keep/drop。

3. **Whole-section keep-drop**：`degrade_previous_compacted_view_for_recovery` 按固定优先级 `EVIDENCE_BACKED_FACT > REFERENCE_CONTINUITY > ANSWER_ANCHOR > FORWARD_INTENT > SESSION_SUMMARY` 做 section-aware degrade，保留完整 section 或丢弃完整 section。

4. **Chunking with provenance**：evidence block 现在返回完整的 single block（`whole-item`），不再做字段级 chunk。如需 chunk，必须通过 `PromptLocalProvenanceEntry.chunk_parent_label` / `chunk_ordinal` 带 provenance 表达。

5. **Fail closed**：`_load_context_fallback_tx` 从不一致时返回 `None`（静默降级）改为 raise `HostDurableError`（fail closed）；`_run_session_allows_proactive_compaction` 检查 Session 仍 OPEN 才提交 compaction；`_validate_fallback_protected_groups` 检查 turn group 一致性；`_selected_material_render_view` 检查 digest / source refs / block id 一致。
