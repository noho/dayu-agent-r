## Findings

### 验证详情

**1. `--primary` occurrence 保留与 append 不吞重复**

- `arg_parsing.py:929`：`action="append"` 每次 `--primary` occurrence 追加到 list。
- `test_arg_parsing.py` `test_upload_filing_primary_is_append_only_on_filing_command`：`["first.pdf", "second.pdf"]` 断言保留全部 occurrence。
- CLI 不做 dedup 或 last-wins；重复 occurrence 原样传给 Fins owner，由 `_select_fins_upload_filing_files` 在 L1024-1025 拒绝 `len(primary_selectors) > 1`。

**2. CLI `--primary` 只注册在 `upload_filing`**

- `arg_parsing.py:928-933`：`_register_upload_filing_command` 内注册。
- `arg_parsing.py:938+`：`_register_upload_material_command` 与 `_register_upload_filings_from_command` 不注册 `--primary`。
- `test_arg_parsing.py` `test_upload_filing_primary_is_append_only_on_filing_command`：`upload_material` 和 `upload_filings_from` 传 `--primary` 均 `SystemExit(EXIT_USAGE_ERROR)`。

**3. raw `primary_selectors` 到 static validator 生效链**

- `fins.py:683-686`：CLI 把 `args.primary or ()` 逐项 `Path.expanduser().resolve(strict=False)` 投影为 `primary_selectors` tuple。
- `upload_tools.py:382-387`：tool adapter 把 optional string 投影为 0/1 tuple；material 时 `raise ValueError`。
- `ingestion_runtime.py:1101-1110`：static validator 先 normalize，再传给 `_select_fins_upload_filing_files`。
- `ingestion_runtime.py:1024-1036`：selector cardinality（>1 拒绝）、multi-file missing（拒绝）、membership（拒绝）均在 workspace mutation 前完成。
- 两条路径（CLI / tool）最终汇入同一 static validator，无第二套业务校验。

**4. tool schema `primary` optional string / `files` maxItems=100**

- `upload_tools.py:242-245`：`"primary": {"type": "string", "description": FINS_UPLOAD_FORMAT_TEXT.upload_tool_primary}`。
- `upload_tools.py:240`：`"maxItems": 100`。
- `upload_tools.py:305-306`：`required=("ticker", "upload_kind")`，primary 不在 required。
- `test_fins_ingestion_tools.py`：断言 `primary_schema` 结构、`files_schema["maxItems"] == 100`、`"primary" not in required`。

**5. filing 0/1 selector、material primary fail closed**

- `upload_tools.py:382-387`：`_upload_primary_selectors_from_arguments` 对 material 直接 `raise ValueError("primary must be omitted for material uploads")`。
- `ingestion_runtime.py:1095-1096`：delete 携带 primary 时 `_raise_upload_usage(PRIMARY_NOT_ALLOWED_FOR_DELETE)`。
- `test_fins_ingestion_tools.py` `test_upload_tool_adapter_projects_zero_or_one_filing_primary_selector`：material 携带 primary 时 `pytest.raises(ValueError)`。
- `test_fins_ingestion_tools.py` `test_upload_tool_invalid_primary_fails_before_state_or_observation_registration`：outside-files 与 delete 场景均在 state/observation 前拒绝，且 `state_repository.calls == []`、`executor.submitted_job_ids == ()`、`runtime._observations == {}`。

**6. invalid combos 在 state/job/mutation 前失败**

- `_validate_fins_upload_filing_static` 在 L1060-1135 完成所有静态校验后才构造 `_StaticFinsUploadFilingValidation`。
- `validate_fins_upload_filing_request` 在 L1243 先调用 static validator，再读 published state。
- tool adapter 在 `__call__` 中 L99 先 `_upload_request_from_arguments`（含 static validator），成功后才 `prepare_observed_upload`。
- 测试明确断言 failure 时零副作用。

**7. CLI help 与 tool schema 机械消费唯一文本 owner**

- `arg_parsing.py:926`：`help=FINS_UPLOAD_FORMAT_TEXT.filing_files`。
- `arg_parsing.py:932`：`help=FINS_UPLOAD_FORMAT_TEXT.filing_primary`。
- `upload_tools.py:238`：`"description": FINS_UPLOAD_FORMAT_TEXT.upload_tool_files`。
- `upload_tools.py:244`：`"description": FINS_UPLOAD_FORMAT_TEXT.upload_tool_primary`。
- `upload_format_contract.py:560-584`：`_project_filing_primary_rules` 按入口字段名投影同一组规则，CLI 用 `--files`/`--primary`，tool 用 `files`/`primary`。
- `test_arg_parsing.py`：断言 `files_action.help == FINS_UPLOAD_FORMAT_TEXT.filing_files` 和 `primary_action.help == FINS_UPLOAD_FORMAT_TEXT.filing_primary`。
- `test_upload_format_contract.py`：断言四个文本字段的 exact projection 内容。

**8. LLM-facing 文本自足且无内部术语**

- `upload_tool_primary`：仅含业务规则（单文件可省略、多文件恰好一个、membership、顺序不决定角色、delete 禁止、material 不使用、不能推断角色）。
- `filing_primary`：CLI 帮助文本，同源规则，字段名为 `--files`/`--primary`。
- `test_fins_ingestion_tools.py`：断言 forbidden fragments 不出现——`"Path"`, `"tuple"`, `"Host"`, `"Engine"`, `"asset identity"`。
- `test_arg_parsing.py`：断言 `"首文件是主文件" not in help_text`。

**9. 无首项/顺序推断**

- `upload_format_contract.py:613`：`"已选主文件必须实际转换成功"` 替代旧版 `"首文件是主文件"`。

- 所有测试断言 `"首文件是主文件"` 不再出现。

- 改动仅涉及 CLI arg registration、CLI prevalidation、tool adapter、text projection 与测试。

- 新增函数 `_upload_primary_selectors_from_arguments` 和 `_project_filing_primary_rules` 均有完整中文 docstring（参数、返回值、异常）。
