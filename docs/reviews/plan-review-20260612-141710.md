### Finding 1: Field-path helper 签名和路径拼接规则已明确

- **Original concern (AgentDS F-01)**: Plan 未定义 helper 签名规范——`field_path` 是独立参数、前缀拼接还是通过父级 dataclass field name 推导。实现 Agent 需自行设计 field_path 组合机制。
- **Plan fix evidence**:
  - Implementation Decision #5 (line 169-178): 显式定义 `_field_path(parent, key)` 和 `_item_path(parent, index)` 两个 join helper，含签名语义和调用规则。
  - `_field_path(parent: str, key: str) -> str`: 当 `parent == ""` 返回 `key`，否则返回 `f"{parent}.{key}"`。
  - `_item_path(parent: str, index: int) -> str`: 返回 `f"{parent}[{index}]"`；调用者必须传入非空数组字段路径。
  - 给出完整 helper 签名示例：`_required_value(source, key, *, parent_path) -> JsonValue`、`_required_string(source, key, *, parent_path) -> str`、`_required_array(source, key, *, parent_path, max_items) -> tuple[JsonValue, ...]`、`_optional_non_negative_int(source, key, *, parent_path) -> int | None`、`_required_enum(source, key, *, parent_path, allowed_values) -> str`。
  - 明确 helper 错误消息必须使用 `_field_path()` 或 `_item_path()` 产生的完整路径，不得仅用 leaf key。
  - 稳定路径示例：`evidence_backed_facts[0].evidence_kind`、`answer_anchors[0].anchor_items[1].ordinal`。
- **Status: 已修复**
- **Verification notes**: Field-path join helpers 语义完整，签名明确，路径构造规则自足。实现 Agent 无需自行设计。

### Finding 4: json.loads 到 JsonValue 的类型收窄模式已具体化

- **Original concern (AgentDS F-04 + AgentMiMo F03)**: Plan 正确识别了 `cast` 消除问题但未提供类型收窄的参考模式，实施 Agent 可能在中间步骤引入 `Any`。
- **Plan fix evidence**:
  - Implementation Decision #4 (line 163-168): 给出完整 narrowing pattern：
    - `parsed: JsonValue = json.loads(raw)` immediately after malformed JSON handling
    - `_json_object(value: JsonValue, field_path: str) -> Mapping[str, JsonValue]` validates `isinstance(value, Mapping)` and every key is `str`
    - Array helpers accept `JsonValue`, validate `Sequence` / list semantics without treating `str` as array, enforce max item count
    - Recursive helpers use `isinstance` to narrow each concrete JSON member before returning typed values
    - 显式禁止：`Any`、`object`、`# type: ignore`、broad `cast(...)`。若 pyright 无法 narrow，加更小的 helper 而非 weaken type boundary
- **Status: 已修复**
- **Verification notes**: Narrowing pattern 从 `json.loads` -> `JsonValue` 注解 -> `isinstance` narrowing -> typed helpers -> candidate constructors 的完整链路已具体化。禁止事项明确，fallback 路径（stop and redesign）有定义。
