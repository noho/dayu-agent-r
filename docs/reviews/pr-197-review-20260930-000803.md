- **HK discovery 的年度锚点只来自本次批次**：`select_hkexnews_report_candidates` 用 `annual_end_dates(tuple(item.title for item in unique))` 从**本次请求拉回的公告**推导年度截止日证据。实测（同一数据路径直接调用）：同一标题「截至2025年3月31日止三個月業績公告」+`category_text="季度業績"`，`annual_ends=()` 时 `resolve_hk_report_period` 返回 `None`（无候选），带 2024-12-31 年度公告证据时返回 `(2025, Q1)`。因此显式窄窗口（例如 `--start 2025-04-01 --end 2025-05-31` 只覆盖季度公告、不含年度业绩）会让季度候选**静默消失**并计入 missing periods；旧的「三个月→Q1」规则会给错财期，所以新行为是 fail-closed，但 README 只在 **rebuild** 段说明「缺少年度依据可先下载对应年度业绩」，**未说明 discovery 也有同一前提**。需确认这是否是有意的取舍，以及是否需要在 README 的 discovery 段补一句前提。
