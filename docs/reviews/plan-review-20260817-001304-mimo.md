## Findings

无 findings。以下逐项说明验证结论。

### 验证 1：两个 structural fake 实现 required batch method

**直接证据**：`repository_protocols.py:402-453` 定义 `FilingUploadStateRepositoryProtocol`，包含两个 required method：
- `read_filing_upload_state(ticker, document_id) -> FilingUploadPublishedState`
- `read_filing_upload_state_in_batch(batch: BatchToken, document_id: str) -> FilingUploadPublishedState`

**当前 state**：`_FixedFilingUploadStateRepository`（line 10681）和 `_ForbiddenFilingUploadStateRepository`（line 10641）均只实现 `read_filing_upload_state`，缺少 `read_filing_upload_state_in_batch`。

**amendment 方案**：两个 fake 新增 `read_filing_upload_state_in_batch(batch: BatchToken, document_id: str)`，签名精确匹配 protocol。方案正确。

### 验证 2：独立 batch_calls

**amendment 要求**：`batch_calls: list[tuple[BatchToken, str]]`，独立于既有 `calls: list[tuple[str, str]]`。

**语义正确性**：`calls` 记录 `(ticker, document_id)` 元组（published state read），`batch_calls` 记录 `(BatchToken, document_id)` 元组（batch state read）。类型不同，不可能混淆。独立记录是唯一正确方案。

### 验证 3：Forbidden fail-fast

**当前行为**：`_ForbiddenFilingUploadStateRepository.read_filing_upload_state()` 先记录 `self.calls.append((ticker, document_id))` 再 `raise AssertionError`。

**amendment 要求**：`read_filing_upload_state_in_batch` 同样先记录 `self.batch_calls.append((batch, document_id))` 再 `raise AssertionError("...")`。

**语义正确性**：static admission 阶段禁止任何 filing state read（包括 batch state read），AssertionError 固定了该边界。方案正确。

### 验证 4：Fixed 返回固定 state

**amendment 要求**：`_FixedFilingUploadStateRepository.read_filing_upload_state_in_batch` 记录 `(batch, document_id)` 后返回初始化时传入的固定 `state`。

**语义正确性**：与既有 `read_filing_upload_state` 行为对称——都是记录调用后返回同一固定 state。方案正确。

### 验证 5：移除 cast 是最小且 owner 正确的 fixture 迁移

**直接证据**：`_build_static_admission_guarded_runtime()` line 10821-10824 使用 `cast(FilingUploadStateRepositoryProtocol, state_repository)` 绕过 structural check；`_build_fixed_state_guarded_runtime()` line 10865 直接传入 fake，无 cast。

**amendment 要求**：移除 cast，与 `_build_fixed_state_guarded_runtime()` 对称。

**最小性判断**：
- 替代方案 A（保留 cast + 给 fake 加 method）：cast 变成冗余，但仍掩盖 conformance signal，违反 "让 pyright 真实执行 protocol conformance" 目标。
- 替代方案 B（移除 cast + 不加 method）：pyright 报错，不可行。
- amendment 方案（移除 cast + 加 method）：最小必要变更，两个 builder 对称，pyright 真实验证两个 fake conformance。

方案正确且最小。
