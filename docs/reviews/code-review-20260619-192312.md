测试链路：
1. 写入 2 个 run 的历史数据：`run-reactive-floor-old`（单 user input）、`run-reactive-floor-recent`（user input + RUN_SUCCEEDED final answer + TOOL_RESULT_ACCEPTED evidence）

3. 构造 `_ValidatedCandidate` → 直接调用 `_frozen_reactive_material_blocks(context, display_text, material_view)`
4. 对 frozen blocks **直接断言**：

   ```python
   # CURRENT_INPUT_ANCHOR 断言
   assert len(current_blocks) == 1
   assert current_blocks[0].canonical_source_refs == ("event-input-dispatch",)

   # Protected blocks 不是 current anchor
   assert all(block.section is not CompactMaterialSection.CURRENT_INPUT_ANCHOR
              for block in protected_blocks)

   # Protected blocks 包含全部三种 turn-group block kind
   assert CompactMaterialBlockKind.USER_INPUT in protected_kinds
   assert CompactMaterialBlockKind.ASSISTANT_FINAL_ANSWER in protected_kinds
   assert CompactMaterialBlockKind.ACCEPTED_TOOL_EVIDENCE in protected_kinds

   # 具体文本内容断言
   assert any(block.text == "recent reactive protected material" for block in protected_blocks)
   assert any(block.text == "recent reactive protected final answer" for block in protected_blocks)
   assert any("recent reactive protected evidence" in block.text for block in protected_blocks)
   ```

5. 然后验证 selection 层也尊重 floor（`excluded_reason_codes[block.block_id] == "protected_recent_raw_floor"`）

**核实**：测试直接调用生产代码 `host_engine_ingest._frozen_reactive_material_blocks`，不通过 scheduler proxy。对输出 block list 逐项断言 kind 组成、current anchor 唯一性和 protected block 的非 anchor 性质。覆盖了 plan 要求 9 的全部断言项。
