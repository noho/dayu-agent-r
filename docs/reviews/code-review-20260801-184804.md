**结论：CR-005 测试证据完整，满足裁决要求。**

#### 3b. TTY REPL 状态机（F09）

**文件：** `dayu/cli/session_execution.py:_drive_interactive_tty_repl`（第 1186-1477 行）

**状态机路径验证（沿真实代码逐行走读）：**

- **正常 submit → terminal → idle 循环**：
  1. composer SUBMIT event → `current is None` → `_start_interactive_turn`（第 1343-1359 行）
  2. `current.submit_task` 完成 → terminal 处理（第 1256-1291 行）
  3. `current = None`, `queued = None` → `composer.set_phase(IDLE)`（第 1289 行）
  4. 回到循环顶部继续等待。

- **Type-ahead sole QUEUE**：
  1. First submit → `current` 创建（第 1343 行）
  2. Second submit while `current is not None` and `queued is None` → `queued` 创建（第 1360-1372 行）
  3. Third submit while both occupied → stderr 消息，不调用 `accept_submit`（第 1375-1376 行）
  4. Current terminal 后 `queued` 被 promote（第 1281-1287 行）。

- **Ctrl+C active → cancel**：
  1. Composer CANCEL_ACTIVE 或 sigint_task 触发（第 1377-1394 行或第 1428-1436 行）
  2. `_request_interactive_cancel` 合并 cancel_reason（第 1705-1706 行）
  3. Pre-acceptance → `acceptance_task` 等 exact run_id（第 1712-1713 行）
  4. Post-acceptance → `_start_interactive_cancel_task` 发起 Host graceful cancel（第 1717-1722 行）

- **Double Ctrl+C → exit-after-cancel**：
  1. First cancel → `cancel_reason` 已设置
  2. Second Ctrl+C（composer 或 OS SIGINT）→ `exit_intent = EXIT_AFTER_CANCEL`（第 1388-1394 行或第 1437-1443 行）
  3. Current terminal 完成后 `current is None` + `EXIT_AFTER_CANCEL` → `return EXIT_KEYBOARD_INTERRUPT`（第 1445-1451 行）

- **LOST → deferred exit**：
  1. Current terminal `!= EXIT_SUCCESS` → `deferred_exit_code = terminal_exit_code`（第 1276-1277 行）
  2. 如果 `queued is not None` → promote → 等 queued terminal
  3. `current is None` + `deferred_exit_code is not None` → `return deferred_exit_code`（第 1449-1450 行）

- **Stale control event guard**：
  - 第 1325-1332 行：`CANCEL_ACTIVE` 和 `TOGGLE_ACTIVITY` 在 `completion.generation != generation` 时判为 stale 并丢弃。

- **Cancel waiter failure propagation**：
  - 第 1310-1319 行：cancel task 先于 submit task 完成且非成功 → 立即 `await current.cancel_task` 传播错误，不等可能永不出现的 submit terminal。

- **Abnormal termination cleanup（finally 块，第 1464-1477 行）**：
  - `normal_completion` 为 False 时取消所有 active/queued submit tasks 和 cancel tasks。
  - 始终清理 composer_task 和 sigint_task。

- **Idle double Ctrl+C revision 保护**：
  - 第 1400-1409 行：`idle_interrupt_revision == event.input_revision` 确保两次 Ctrl+C 之间用户没有编辑，防止误退出。
