### 1-未修复-低-批量脚本再生成注释未拒换行：raw material form 的边界换行会生成语法损坏的已发布脚本

- **入口/函数**: 真实 CLI `dayu-cli upload_filings_from`（`_run_upload_filings_from` → `_single_batch_material_form` → `_upload_batch_regeneration_argv` → `render_upload_script`/`_render_posix_script`）。
- **文件(行号)**: `dayu/cli/commands/fins.py:1229-1236`（`_single_batch_material_form` 现返回 raw 候选）；`dayu/cli/upload_script.py:170-171`（POSIX 把 regeneration argv 经 `shlex.join` 直接写入 `# Regenerate:` 注释）；对照 `dayu/cli/upload_script.py:199-231`（Windows 分支对同一 argv 显式 `_validate_windows_batch_argument` 拒 NUL/CR/LF）。
- **输入场景**: `--material-forms` 传入带首/尾换行的合法候选，例如 argv 值 `"EARNINGS_PRESENTATION\n"`（校验 `strip().upper()` 后等于合法枚举，合法通过）。
- **实际分支**: `_single_batch_material_form` 保留 raw（不再 strip/upper）→ `generate_upload_batch_plan` 校验通过 → regeneration argv 携带含 `\n` 的原值 → POSIX renderer 写入注释。
- **预期行为**: CLI 报告成功时发布的脚本必须可被 `sh` 解析执行；不可执行输入应在生成前被拒（与 Windows 分支一致）或被安全投影。
- **实际行为**: CLI exit=0 并发布脚本，但脚本注释跨行断裂，留下未闭合单引号吞并后续命令行；`sh -n` 报 `syntax error`（exit 2），脚本整体不可用。
- **直接证据**: 本人以真实 CLI（隔离 tmp）复现：`python -m dayu.cli upload_filings_from --base <tmp>/ws --ticker AAPL --from <tmp>/inputs --material-forms $'EARNINGS_PRESENTATION\n'` → exit 0、`Generated upload script: …/upload_filings_AAPL.sh`；该脚本第 3-4 行为 `# Regenerate: … --material-forms 'EARNINGS_PRESENTATION` / `'`；`sh -n` exit=2（`unexpected EOF while looking for matching '`）。反例对照：`--material-forms $'x\nEARNINGS_PRESENTATION'`（非空白 payload）在生成前被拒 exit 2、无 workspace，证明**不可注入任意命令**，影响限于脚本损坏。基线对照：base 版本该值经 `_normalized_text_tuple` 的 `strip()` 后为 `EARNINGS_PRESENTATION`，注释单行、脚本合法；本片改为 raw 后首次可携带边界换行到达该出口。同时说明：渲染器对换行不设防这一根因先于本片存在（`--filing-date`/公司名内部换行等原样字段亦可到达该注释），本片使 `--material-forms` 成为新的携带者。

- **建议改法和验证点**: 在脚本安全 owner（`render_upload_script`）对 POSIX 与 Windows 统一拒绝 regeneration/command argv 中的 CR/LF（复用 `_validate_windows_batch_argument` 判据），使 CLI 在发布前以明确错误失败；或在 batch 投影处对 raw 候选做“可用于脚本”约束。验证点：`--material-forms $'EARNINGS_PRESENTATION\n'`、`$'\nEARNINGS_PRESENTATION'`、`$'\rEARNINGS_PRESENTATION'` 三条真实 CLI 断言“无脚本发布+非零退出”，且普通含空格/中文候选仍生成单行合法注释（`sh -n` exit 0）。
- **修复风险（低/中/高）**: 低（只加发布前校验或投影约束，不改已生成合法脚本的字节）。
