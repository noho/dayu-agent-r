# docling table_mode accurate vs fast 定向研究（40 份分层样本）

- 日期：2026-09-17
- 目的：为「生产是否把 table_mode 从 accurate 切到 fast」提供数据
  （背景：根因报告 `docling-regression-8492e128-rootcause.md` 确认 docling 2.118+ 的
  accurate 模式在特定表格上丢弃数据行）
- 配置：生产路径 `dayu.documents.docling_runtime.convert_pdf_bytes_with_docling`，
  仅切换 `table_mode`，其余默认（do_ocr=True、do_cell_matching=True、
  backend=docling-parse、device=auto）
- 样本：40 份分层抽样（见第 1 节）
- **证据等级**：第 1-4 节全部为 **Tier-0（程序化指标）**——数字多重集与结构统计
  均为机器计算，可复核；第 5 节为**质量推断**，明确标注为推断，不构成 Tier-0 证据。

## 1. 样本分层与指标口径

### 1.1 样本分层（40 份，来自 250 份样本库）

### 1.2 指标定义（Tier-0）

- **表格数字保真（模式间直接对账，主口径）**：对每份样本分别拼接
  texts ∪ table_cells 文本，抽取数字 token 多重集（正则
  `-?(?:\d{1,3}(?:,\d{3})+|\d+)(?:\.\d+)?%?`），直接比较两模式：
  - `fast 独有` = Σ max(0, fast_c − accurate_c)，即 fast 有而 accurate 没有的 token 数
  - `accurate 独有` = Σ max(0, accurate_c − fast_c)
  - **不采用「vs 2.90 基线」作主口径**：基线自身也有缺失与格式差异，
    会把与模式无关的噪声计入（该口径数据仍保留在 1.3 与第 7 节供参考）。
- **表格结构**：tables 数、Σnum_rows、Σnum_cols、最大表网格 num_rows×num_cols。
- **两模式差异规模**：数字多重集 Dice 系数。
- **单页复核（Tier-0）**：对发现差异的样本，抽取相关页为单页 PDF，
  用生产路径在两模式下重新转换，逐 token 核对（第 4 节）。

### 1.3 备用口径（vs 2.90 基线，仅供参考，不作结论依据）

- 合计：accurate 缺失 1553 / 新增 827；fast 缺失 1557 / 新增 865（40 份合计）
- 该口径下「accurate 有缺失且 fast 找回」2 份、「fast 反向变差」7 份，
  但差异量级多为 1-6 个 token，且含大量基线与新版本之间的格式/切分差异噪声，
  因此不作为主判据。

对第 2.3 节中疑似含真实数据的两个样本，抽取相关页为单页 PDF 后在两模式下

### 4.1 `fil_cn_1a8ad265…`（扫描件，230 页）

| 页 | token | accurate（merged / 表格单元格内） | fast（merged / 表格单元格内） |

## 5. 质量推断（**推断，非程序化指标**）

以下为基于第 1-4 节 Tier-0 数据的**推断**，供处置裁决参考，不构成证据：

1. **对文本型年报，fast 的数字保真优于 accurate**（推断）：
   退化样本上 fast 精确找回全部 5 个丢失的财务数字、14/14 关键 token ≥ 基线；
   另一扫描件样本 `9ecc689b9` 上 fast 找回 3 个真实量级数字
   （`447,915,000`/`21,397,000`/`5,000,000,000`）。这与根因报告中
   "accurate 对触顶 OTSL 序列的解析路径退化"的机制一致。
2. **fast 并非单边更优，存在真实反向损失**（推断）：
   2 份样本经单页复核确认真实数据 token 丢失（`441597`、`24,216`、`8,072`×2 等），
   另有 6 份存在 1-6 个 token 的差异（未复核，多为日期/小整数片段）。
   因此**全局切换是 trade-off，而非纯粹的改进**。
3. **fast 的表格结构无明显系统性变差**（推断，基于 Tier-0 结构统计）：
   tables 数 40/40 相同；Σrows 差异中位数 −2（范围 −83~+249）；
   Σcols 中位数 0；max_grid 中位数 +5（21 份更大 / 12 份更小）。
   结构指标接近持平，未观察到单向劣化，但分布两端存在 ±100 量级的个体差异。
4. **两模式输出高度重合**（Tier-0 支撑）：23/40 份数字多重集完全相同，
   38/40 份 Dice ≥ 0.999。多数样本上切模式无感知差异。

**数据边界（必须与上述推断同时阅读）**：
- 主口径只统计**数字 token**，不反映表格的语义正确性、行列归属正确性、
  跨行跨列结构、表头层级等（这些需要人工抽检或更强的结构化指标）。
- 「fast 独有」中的许多 token 是日期/小整数片段（年份、`12`、`31` 等），
  不一定代表数据保真提升；第 2.2 节已逐项标注。
- 反向损失仅对 2 份做了单页复核，其余 5 份未复核，不能确认其真实性。
- 扫描件样本量小（7 份），且扫描件的 fast/accurate 差异机制可能与文本档不同。
- 未评估 fast 对**非表格**内容（正文、图表标题等）的影响。
