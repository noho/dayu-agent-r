## New Material Defects Check

The fix changes are minimal and well-scoped:

1. **Constructor trimming** — removed 5 parameters, kept 3. No new coupling introduced.
2. **Early return in close()** — terminal state check before thread check. The `thread is None or not thread.is_alive()` guard prevents early return when the thread is still running (which would skip the join). This is correct because STOPPED/FAILED are only set when the thread is about to exit or has exited.
3. **Self-close RuntimeError** — raises inside `close()`, propagates to `_run_loop` exception handler, recorded as FAILED. Clean error path.
4. **None timeout branch** — `thread.join()` without timeout vs `thread.join(timeout)` + diagnostic. Simple and correct.
5. **Thread clearing** — `if self._thread is thread: self._thread = None` after join. The `is thread` check prevents clearing a new thread started by a concurrent `open()` (though `open()` would raise for a non-terminal supervisor).

No new material defects found.
