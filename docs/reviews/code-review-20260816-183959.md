## Focus 2：Phase A/B gate 位置与 UNSAFE 绝不落入 revision 比较/reset

**通过。**

```python
phase_a_integrity = host._source_repository.classify_source_integrity(...)
if phase_a_integrity.status is SourceIntegrityStatus.UNSAFE:
    raise SourceIntegrityPreflightError(SourceIntegrityPreflightReason.UNSAFE_PUBLICATION)
previous_meta = (
    None
    if phase_a_integrity.status is SourceIntegrityStatus.MISSING
    else host._safe_get_filing_source_meta(...)

```

`UNSAFE` 绝不进入 `previous_meta` 读取、fast skip 判断、provider download、batch begin。

```python
phase_b_integrity = source_repository.classify_staged_source_integrity(...)

    raise SourceIntegrityPreflightError(SourceIntegrityPreflightReason.UNSAFE_PUBLICATION)
if not has_same_source_publication_identity(phase_a_integrity, phase_b_integrity):
    ...
```

`UNSAFE` 绝不进入 identity 比较（该比较对 `UNSAFE` 会抛 `ValueError`）、retry/skip/reset/blob/commit。异常路径的 rollback ownership 正确：CN Phase B 在 `_commit_cn_filing_assets_batch` 的 try/except 内，`SourceIntegrityPreflightError` 继承 `RuntimeError`，被 catch 后执行 `rollback_batch` 并 re-raise。SEC Phase B 在 `run_download_single_filing_stream` 的 try/finally 内，token 在 finally 中 rollback。
