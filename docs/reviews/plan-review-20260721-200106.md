## 1. 4 个 utils caller 是否确实是 async factory contract 的真实 direct callers

**代码证据验证**：

| 文件 | 行号 | 调用模式 |
|---|---|---|
| `utils/smoke_host_public_r03_semantic_ownership.py` | 405 | `watcher = host.watch_session_events(session.session_id)` |
| `utils/smoke_host_public_multiturn.py` | 388 | `watcher = host.watch_session_events(session.session_id)` |
| `utils/smoke_host_public_conversation_memory.py` | 437 | `watcher = host.watch_session_events(session.session_id)` |
| `utils/smoke_host_public_conversation_memory_scenarios.py` | 3011, 3110 | `watcher = host.watch_session_events(session.session_id)` |

全部 5 处调用均为同步调用 `host.watch_session_events(session.session_id)`，返回值直接作为 async iterator 传入 `_run_round(...)`。当 factory 变为 async 后，这些调用返回 coroutine object 而非 iterator，会导致 pyright error 与 runtime failure。

**结论**: ✅ 确认 4 个文件均为 `Host.watch_session_events` 的真实 direct callers。机械 `await` 是唯一正确的 owner-boundary fix。

## 2. 机械 await 是否为正确 owner-boundary fix

- async factory contract 的唯一 owner 是 `dayu.host.api.Host.watch_session_events`（§4.1 Owner map）。
- 所有 direct callers 必须消费 async contract，不能用同步兼容分支绕过。
- 4 个 utils 文件是 smoke 脚本，不持有 `watch_session_events` 的语义所有权，只需做机械 `await` 传播。
- Controller 裁决明确禁止：同步 factory compatibility branch、lazy attach、pending future、下游 coroutine 识别、`cast`/`getattr` shim。
- plan-fix 已在 §7 S1 Non-goals 新增对应禁令。

**结论**: ✅ 机械 `await` 是正确的 owner-boundary fix。
